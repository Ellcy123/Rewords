## 一条完整循环

小屋选择章节/起始猫→4×4空窝，猫先在待放区→购买、拖放和连接→自动战斗→普通层胜利发奖并保留阵容→继续爬楼→末层成功领常规/首通奖励或失败结束→保留账号成长，新局重新构筑。

章内阶段解锁立即保留，不因后面失败回收。去小屋培养后在下一场生效，正在进行的战斗固定快照。首版不开放广告复活；不看广告也有完整通关与成长路径。

## 关键工作选择

- 猫各有自身本领，每局同种一只；永久等级1—10，不改变形状、攻速和触发次数。
- 用品只做局内构筑，贴边与专属条件清楚；同类不重复叠加，一件可服务多猫。
- 金币用于当前局购买/刷新/扩容，培养币用于账号猫等级；不设体力、钻石、碎片、抽卡和装备栏。
- 六个成长任务、三个每日目标、七次累计签到；不把看广告设成任务。统一北京时间05:00换日。
- 三处自愿激励视频，每日成功上限共7次；实际观看与收入未预测，正常奖励无需视频。
- 8章配表保证第7章解锁的最后内容在第8章能出场。76个楼层参数不等于76种独立敌人或本轮全部实现。

九份调研保存来源链接、资料年代、纯IAA/广告主导/混合对照、可借鉴和不可照搬部分。国内样本为主，包含花园特攻队、高手大闯关、吃不到我呀、躺平发育等，向僵尸开炮等明确作为混合变现对照；没有把公开资料研究说成亲自试玩或所有机制当前版本仍相同。
