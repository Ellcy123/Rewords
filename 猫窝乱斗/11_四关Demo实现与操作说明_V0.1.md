# 四关 Demo 实现与操作说明 V0.1

日期：2026-09-26。对应用户授权：按架构规划重构底层，并完成第 1、2、3、4 关。本文记录实现口径；测试结论以独立报告为准。

## 现在做到了什么

一局从第 1 关开始，购买、摆放、自动战斗、结算，再带着全部猫、用品和金币进入下一关。第 4 关胜利后显示四关完成。暂用方块、文字和简单打击反馈，不代表最终画风。

- 内容：面条、锤锤、枕头；逗猫棒、哑铃铛、发条鼠、小鱼干、旧软垫、歪头夜灯。
- 操作：购买后到待放区，拖入方形盒子；点选后旋转、换姿势、移回待放；非法落位保持原状态。待放区横向滚动可容纳多件物品。
- 连接：正交贴边生效，同类用品对同只猫只计一件，一件用品能服务多只猫。点选猫显示有效连接清单，并高亮连接用品；点选用品高亮受益猫。
- 战斗：多猫独立攻击和技能计数、全队生命和护盾、25 秒上限。分开的连击反馈和猫的冷却／技能进度帮助观察组合。
- 经济：固定教学货架，后续轮换商店，首次免费刷新，付费刷新，出售按买入价一半向下取整，4→5→6 的方形扩容。
- 失败：免费回准备区调整；掉血失败可使用一次模拟广告，增加 20% 最大生命重新开打；超时不给广告重打。没有付费复活。
- 保存：成功操作后保存，保留备份；准备、胜败结果和商店次数跨重启保留；战斗中退出从本次阵容重新开打。关卡奖励与广告有结算记录，避免重复领取。
- 广告：只有本地“模拟完成／取消”面板，没有接商业 SDK。每关模拟金币广告 +4 一次。

## 前四关怎么走

| 关卡 | 梦魇 | 生命 | 攻击 / 间隔 | 商店与体验 |
| --- | --- | ---: | --- | --- |
| 1 | 床底的手 | 32 | 3 / 3 秒 | 只有逗猫棒，学贴边加速 |
| 2 | 倒走闹钟 | 50 | 4 / 3 秒 | 哑铃铛、逗猫棒，强化每一击 |
| 3 | 衣柜长影 | 70 | 5 / 3 秒 | 发条鼠、哑铃铛、逗猫棒，连击追加伤害 |
| 4 | 偷梦的客人 | 160 | 6 / 2.5 秒 | 开放其他猫、更多用品、出售和扩容 |

前三关按 09 文档实现；教学商品已持有的不再出售。每关首胜给 6 金币，最后一关也展示这笔奖励，但不进入不存在的第 5 关。

**第 4 关具体数值和名字是本轮补齐的暂定方案，不冒充此前用户逐项确认。** 目的是让已有连击路线继续有用，同时允许试重击／护盾搭配。不是强制必须扩容才能赢。是否需要强化难度和打击感，要通过试玩调整，当前不宣称平衡已定稿。

第 4 关货架三批循环：

1. 锤锤 / 枕头 / 旧软垫。
2. 小鱼干 / 歪头夜灯 / 逗猫棒。
3. 哑铃铛 / 发条鼠 / 面条。

首次刷新免费，以后每次 1 金币；买过的空位在刷新后更换。允许再买同种猫，但重复用品不会对同一只猫无限叠加。

## 不再是第一关硬编码的原因

| 文件 / 层 | 责任 |
| --- | --- |
| `Assets/CatGame/Core/Definitions.cs` | 配置数据、实例状态、占格和连接规则；不引用 Unity |
| `Core/ContentRules.cs` | 配置引用、占格、数值的启动校验 |
| `Core/Battle.cs` | 冻结开场属性，多猫调度、技能与结构化表现事件 |
| `Core/RunSession.cs` | 命令入口，购买／摆放／关卡／结算／广告；UI 不直接改钱 |
| `Runtime/GameContent.cs` | ScriptableObject 权威配置及 Sprite、字体引用，运行时复制配置 |
| `Runtime/JsonRunStore.cs` | 文件原子替换、备份恢复、模拟广告提供方 |
| `Presentation/` | uGUI 画面、安全区、指针拖放、选择高亮和反馈 |
| `Editor/DemoSetup.cs` | 首次初始化配置与场景、独立构建入口 |
| `Tests/` | Luna 维护的 EditMode / PlayMode 测试 |

刻意没有做通用技能脚本语言、服务器或大型框架。三类猫的技能行为使用枚举，数值和占格来自配置；已有机制增加猫无需复制场景，新增技能机制仍需写规则并增加测试。

本轮将同类配置集中在一个 GameContent 资产，而非为每种配置创建大量小资产。UI 坐标采用 540×960 逻辑画布，自动适配安全区；美术替换通过视觉引用，不把图放进规则层。当前只有 Sprite 和字体接入，正式 Prefab、音效资源将在美术批次接入，不能算已完成。

时间精度为 0.1 毫秒；1.25 秒与 1.5625 秒可以精确表示。追加攻击生成独立表现事件，但不增加普攻计数、不再次触发技能。相同逻辑时刻先收集猫的伤害和新增护盾，再结算敌人伤害，双死按失败。

## 在 Unity 里从哪里改

- 正式场景：`Assets/CatGame/Scenes/CatRun.unity`。
- 配置资产：`Assets/CatGame/Resources/GameContent.asset`，Inspector 中展开 definition，再改 pieces / stages。
- `Cat Game/Set Up Four Stage Demo` 只在缺少配置或场景时新建，不覆盖已有策划数据或场景。
- `Cat Game/Build Four Stage Demo` 只构建已存在的场景，不再先重建场景。
- 旧 `Assets/CatDemo` 仅保留作历史行为参照，已经不是构建入口。
- 中文字体使用 Google Fonts 的 Noto Sans SC，许可证随字体保存为 `Fonts/OFL.txt`。

本轮用内置 uGUI 2.0.0 / Test Framework 1.6.0，与本机 Unity 6000.4.0f1 同版本编辑器捆绑提供。

## 本轮边界

10 猫 / 20 用品、猫成长、后续更多关卡、正式美术、音效、真实广告 SDK、手机真机触摸与性能验证，仍是后续工作。不能把四关可玩等同于 IAA 可上线。

Pipeline 实时连接此前存在独立端口启动故障。CLI 批处理可以作为编译、测试和构建路径，连接问题与游戏代码是否通过分别记录。
