# UX 网页示意验证

日期：2026-09-29。使用 Playwright 1.62.1 与本机 Chrome 154，访问 `http://127.0.0.1:8876/`。

通过的项目：

- 990×1000 桌面首屏中，准备与战斗画幅并排，各为 390×693.33；标签切换栏隐藏，页面没有横向或纵向溢出。
- 准备底部提示文字与待放区有可见间距。
- 点击购买后金币从 10 变为 7。尝试放在 index 3（横向空间不足）时购买状态、待放物品和金币都保留；随后点击 index 1 成功放置，连接提示出现。
- 开战约 2 秒截图时没有弹层。战斗画幅内没有格子、商店或棋盘 DOM；准备区商店和棋盘处于 inert 状态。
- 暂停 1.6 秒期间敌方血量数值保持不变；恢复后结果弹层出现。点击结果返回后，已购买物品仍在 index 1，联动提示仍在，金币为 7。
- 页面没有 JavaScript 异常。
