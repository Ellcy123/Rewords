# 猫窝乱斗网页示意 v9.2 复核

**结论：PASS。** 使用独立 Chrome 与 Playwright 检查 1280px 桌面、390px 与 360px 窄屏。390×693 的 C 静态图和准备图为纯画幅截图。

视觉上，C 的猫窝生命与 Boss 生命、下一击预告层级清楚。实战约 1.5 秒时猫咪普攻的 `−4` 反馈没有盖住 Boss 预告。猫名与加速标签在 Boss 下方、布窝上方，仍有可见间距；猫窝生命条完整，画幅底部留白清楚。360 窄屏实际缩放为 336×597，名字、血条与预告仍在画幅内，文字可辨。

准备页的商品、金币、购买按钮、加速说明和待放区在 390 与 360 窄屏均可读。购买后金币由 10 降至 7，猫和玩具两张待放卡同时显示；将玩具拖到猫相邻行后，联动提示清楚。
