动作顺序：短起笔 → 爪痕伸长 → 划击与爆点峰值 → 断痕与外散碎片 → 碎片减小 → 少量残屑退出。采用 Codex 内置图像生成直接出六帧图集，无视频抽帧，无补帧。

处理仅为 3×2 等格裁切与 GIF 组装，保留单帧 PNG 原始 alpha。GIF 的蓝灰底只用于展示浅色爪痕，不属于特效素材。循环停顿只用于看样，不表示正式攻击间隔。未导入 Unity，未设置命中逻辑。本次形状与节奏已获用户认可，不因先前记录的柔光差异自动返工；接入角色动作与实际场景时另行适配。
