# 猫爪命中特效试稿

用户授权制作一个特效样例。采用 Codex 内置生成 3×2 六帧图集，切帧后组成短促命中预览；不生成视频。使用动作设计 skill 的准备、峰值、跟随与收势方法，爪痕沿左上到右下划过，爆点与碎片晚于划击出现。

拟定六帧时长：40/50/70/60/70/90ms；末尾添加约 800ms 空白作为演示间隔，不属于攻击节拍。交付原图、单帧 PNG、GIF 和提示词。透明背景优先；以实际返回 alpha 为准，不假称已经抠干净。不是已导入 Unity 的正式特效。

## 实际提示词

Use case: stylized-concept
生成二维手绘休闲游戏《猫窝乱斗》的“猫爪命中”特效精灵图集。横向3:2画布，严格3列2行等分，六个正方形格子，无间隙，无格线，无编号，无文字。透明背景（真实alpha），无背景颜色、场景、猫、爪子本体、敌人、地面。六格是同一个短促特效的连续帧，按左至右上至下顺序。每格特效中心固定在局部正中心，完整图形局限于每格中央65%区域，留足空白不触边。不要给每格画相同大小的完整特效，动作必须明显按阶段变化。
设计：三道略弯的锐利爪痕，从左上快速划向右下，形状有墨笔收尖的锋利感。爪痕使用浅色实心大块面与极少深色墨线，让深浅背景都易读；接触爆点用温暖明快的实色色块，不能有渐变、发光、火焰和血液。
第1帧：只有左上方向的三个很短的尖形起笔，约占单格20%，准备快速划过。
第2帧：三道爪痕伸长到完整长度的约70%，前端收尖、长度错落，形成清楚平行斜向轨迹。
第3帧：全长三爪痕约占单格60%，同一中心位置出现一个小而有力的不规则切纸状爆点，是动作峰值，爆点不覆盖全部爪痕。
第4帧：爪痕断成两三段并明显缩短，爆点展开成五六片大小不同的扁平尖角碎片，沿冲击方向外散。
第5帧：爪痕消失，只剩四片更小的碎片向外移动，形状干净，画面大部分为空。
第6帧：只剩两片非常细小的残屑，位于先前碎片路径的外侧但仍在中央65%区域，准备消失。此帧不能重新画完整爪痕。
美术风格：stylized 2D hand-drawn game VFX, economical expressive ink accents, bold tapered graphic shapes, cut-paper impact silhouettes, clean opaque flat fills, sharp readable negative space, selective asymmetry, minimal detail, no soft glow, no gradients, no airbrush, no realistic smoke, no volumetric lighting, no 3D, no texture noise.
这是用于等格切帧的生产探索图集，不是六张独立插画；严格保持同一个特效中心和运动方向。
