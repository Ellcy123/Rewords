# 背景、年糕猫与 B3 UI 合看

工具：Codex 内置图像生成，三图合成。实际提示词：

Use case: compositing
把提供的三张素材组合成一张《猫窝乱斗》竖屏游戏美术搭配预览。输出2:3竖图，整幅只有一张游戏画面，无外部手机框、无对照分栏。
输入图1：Midjourney卧室背景，作为底图。保留其房间透视、蓝色墙面、月亮窗户、木床、灯、暖色地面及原有线条和纸纹，不重新设计背景，不为了统一画风重绘素材。
输入图2：年糕猫角色。仅提取这一只完整猫，去掉原来米白色背景，将它放在卧室床前的空地上，居中稍偏左；宽度约画面40%，位于全画面高度70%左右。保留原猫的横长软糯身形、歪耳、半睁眼、弯尾、三花斑块、干笔轮廓和纸纹。不得替换成通用可爱猫，不加描边外框、不重画成UI图标风格、不加白底矩形。接地仅极小一块自然阴影。
输入图3：B3纸片UI样板，是组件来源。移除B3版本标识和展示底。将样板中的大纸片面板等比缩小为顶部靠左的紧凑信息卡，宽度约画面44%，只留安静空标题栏和正文留白，别把大弹窗盖在房间中央；保留左上折角、切角、纸片错位衬底。右上可独立放原关闭叉作为小控件。底部横向安排样板中的三个物品格（空格、鱼图标、猫图标），右侧放一个原图黄色播放按钮，宽约22%；底部控件高度约画面12%，底部有安全边距，猫不遮挡UI。只用普通态播放按钮，不显示其余按钮状态。纸片UI保持原B3的细节、线条和配色，不圆角化、不增加装饰。不得将顶部纸片面板的原来宽高比拉伸成细条。
关键：这是现有三个来源的合成搭配预览，不是全画面统一风格的再创作。刻意保留原素材之间的笔触和细节差异，以便判断是否搭配。不能统一滤镜、整体重新上色、自动平滑猫的干笔线、把背景质感传播到UI上。月亮、窗户、床与猫都清楚可见。无新猫、无怪物、无金币、无虚构游戏机制、无文字数字、水印。
