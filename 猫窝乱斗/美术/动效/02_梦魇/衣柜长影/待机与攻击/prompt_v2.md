# 裁切与安全区修正

首稿第4-6帧长影攻击伸展接近格边，需留安全区。实际编辑提示词：

Use case: precise-object-edit
编辑所附《猫窝乱斗》六帧精灵图集，只修正裁切与安全留白，不改变故事、外形、颜色、帧顺序、动作时序。输入图是一张严格三列两行的动作图集，共六个512×512方格。每一格都是同一个衣柜长影与它左侧的细衣柜门缝。将每格内的整组可见画面（门缝、长影、手、脚、所有笔触和残影）整体等比缩小至原来的约78%，然后在原来的方格里居中放置；确保所有可见部分离每格上下左右边缘至少45像素。第4-6帧攻击伸出的长手必须完整呈现，不能跨入相邻格或在边界截断。允许少量调整整体平移以使门缝位置六格一致，不改变长影身形、姿态、弯折结构、攻击方向或任何局部描绘。保持每格内部的透明alpha背景，不要加黑色、蓝色或纸纹背景，不画格线、标签或字。输出依然1536×1024、3×2六格。输入图若有已截断边缘，可自然补齐原有简单的墨色轮廓，不重画成新怪物。
