# cat_noodle_stretch 待机与普攻

参考正式资产：`/Users/m4/project/rewords/猫窝乱斗/美术/导出/首批正式资产/角色/cat_noodle_stretch.png`。Codex 内置图像生成，首三帧待机、后三帧一次普攻。实际提交提示词：

Use case: stylized-concept
以提供的正式透明PNG作为唯一角色身份和配色参考，生成《猫窝乱斗》cat_noodle_stretch六帧动作图集。面条猫伸展姿势，横向细长身体严格位于1×3占格轮廓内。攻击由前爪前探形成短促抓击，身体保持连续柔软弧线；尾巴晚半拍回弹。

精确输出横向3列×纵向2行的六个等大正方形格，按左到右、上到下排列。每格同一只/同一个主体，朝向、体型、颜色、花纹、五官、爪或肢数量、透视、画风完全继承参考图。每格主体占格宽约70%，所有最远端仍距格边至少12%安全区。六格相同画布基线与中心；背景为真正透明alpha，无场景、地面、光晕、格线、文字或编号。
帧1：原姿稳定待机。帧2：极轻微呼吸或悬停，轮廓小幅变化，接触基线不动。帧3：回到接近帧1，供1-3帧循环待机。帧4：准备攻击，重心短促后移或压低。帧5：攻击动作峰值，单一方向前探/抓/拍，姿态清楚，但不超出单格安全区。不画命中特效、爪痕、伤害数字。帧6：收势，主体回到接近帧1，为下一轮待机留下自然衔接。
同一图集里只有这六帧，不重画成六只不同猫或六种敌人，不做多视图角色设定，不能把整张参考图重复贴六次。动作幅度约主体尺寸5%-10%，显眼但不过大。让F1-F3组成待机循环，F4-F6组成一次普攻并接回F1。
