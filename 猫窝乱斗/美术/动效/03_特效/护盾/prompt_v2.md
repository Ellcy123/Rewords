# shield_bloom 第二轮纠偏

首稿错误：生成了不属于独立特效的猫/队伍，不能作为可叠加素材。以下为实际重做提示词：

Use case: stylized-concept
《猫窝乱斗》全队护盾出现特效六帧sprite sheet。只画抽象的手绘纸片护盾弧线与小纸片；绝对不能出现任何猫、鼠、角色、脸、身体、队伍、道具或背景场景。画面中心始终是一个完全透明的空洞，让游戏角色在下面可见。严格3列2行，每格同一正方形，透明alpha背景，无格线文字编号。
F1三片短弧从中心外围出现；F2六片短弧向外排列；F3接近完整的圆角保护环，由约八片不规则平面纸片构成；F4保护环达到最大，仍有间隙，不遮挡中空；F5环裂为五六块更短纸片向外散；F6只剩两三片细小残屑。每帧环形中心固定，全部图形位于单格中间70%以内。二维手绘游戏特效，果断墨线，干净实色块，克制短硬边阴影；不指定特定颜色，但需与明亮背景对比。 no animals, no cats, no faces, no team portrait, no bubbles, no dome, no soft glow, no gradients, no 3D.
