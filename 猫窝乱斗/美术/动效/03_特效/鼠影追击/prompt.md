Use case: stylized-concept
生成《猫窝乱斗》逐帧动作或特效六帧图集。发条鼠触发追加伤害时出现扁平、轻怪诞的鼠影。六帧从蜷起、发条启动、向右前方冲、撞击、轻弹、消散。参考图仅锁定鼠形与发条钥匙身份，阴影是简化剪影，不需复制用品静态图全部细节；飞行轨迹由 Unity 控制。
严格3列×2行，六个等大的正方格，阅读顺序左到右、上到下；同一主体/特效中心在各格相同相对位置，所有可见笔触距格边至少12%，背景真实透明alpha。无格线、编号、文字、手机或场景。F1准备，F2启动，F3扩展，F4动作峰值，F5回落，F6收势；每帧变化清楚但仍是同一动作，首尾可接回静态或消失。猫/鼠参考图的外形、配色、轮廓和身份保持稳定；若无参考，不设项目强制颜色，选择与明亮手绘游戏相容的自洽配色。绘制完整六格而非单幅插画，不用满屏晕光、柔和空气刷、半透明背景渐变。美术风格提示词：stylized 2D hand-drawn game frame animation, bold simplified graphic silhouettes, economical uneven ink accents, clean opaque flat fills, restrained planar shadows, playful offbeat game feel, strong readability at small size, no photorealism, no 3D, no text, no UI
