# heavy_impact 第二轮纠偏

首稿错误：生成了不属于独立特效的猫/队伍，不能作为可叠加素材。以下为实际重做提示词：

Use case: stylized-concept
《猫窝乱斗》重爪命中专用视觉特效六帧sprite sheet。全图只能出现一个抽象的巨大纸片猫爪印与撞击碎片。绝对不能出现猫、动物、身体、脸、角色、剪影、武器、道具、手持物。爪印是孤立的平面符号，不连着任何肢体。六格严格3列2行，每格相同正方形，真实透明alpha背景，无地面、空气背景、格线、字。
F1小爪印符号从画面上方开始下压；F2爪印变大向中心下降；F3巨爪印在中心以清楚硬边轮廓形成峰值，周围三片短尖形冲击碎纸；F4印记碎成四五块，向外散；F5仅剩碎片；F6两块微小残屑消失。全六帧没有角色，画面除爪印与纸碎片外完全透明。每格图形位于中间70%安全区。浅暖色主爪印配深墨色短轮廓与一点更亮的硬边爆点，二维手绘、平涂、局部不规则切角。 no character, no cat, no mouse, no face, no scene, no gradients, no soft glow, no 3D.
