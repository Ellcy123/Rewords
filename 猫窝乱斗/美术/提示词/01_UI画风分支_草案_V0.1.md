## 与角色、背景的关系

继承简练手绘墨线、自然轮廓、干净平涂和克制阴影。UI 强调规则的结构、清楚的层级和操作状态；仅在外轮廓保留少量手绘起伏，避免边框过度扭曲、装饰挤占文字区或缩小后线条消失。通用 UI 画风不限定具体颜色。

按钮与面板生成独立美术组件；文字、数字、排版与交互由 Unity 实现。完整界面图可用于预览，不能直接作为可交互 UI。

## 中文含义

风格化二维手绘游戏 UI，简练果断的墨线，外轮廓带轻微自然起伏，受控且一致的边框粗细，清楚简洁的剪影，干净平涂，克制的块面阴影，极简材质表现；少量局部纹理避开内容区域，内部留白充足，转角造型统一，视觉层级清楚，缩小后仍易读，带克制的俏皮感。避免低幼绘本感、装饰堆砌、满屏颗粒、柔焦、喷枪渐变、塑料光泽、写实材质和三维渲染。

## 单次需求的组织方式

1. 中文描述组件用途与具体设计。
2. 单列形状、比例、文字安全区、状态及交付要求。
3. 有明确配色需求时单列配色，不混入画风段。
4. 追加独立英文 UI 画风段，保存实际提交原文。

## 建议的首批样板范围

- 主按钮：普通、按下、不可用三种状态，轮廓和尺寸对应；状态差异不能只依赖颜色。
- 一个信息面板：明确标题区与内容区，边框不侵入文字安全区。
- 一个物品格与选中态：检验装入猫或用品后，边框是否抢主体。

先用这一小组与现有猫、怪物和 MJ 背景 3 号放在同一画面里比较，再决定是否调整线条与块面。样板通过后扩展其他组件；各类样稿完成后再统一整理完整美术文档。
