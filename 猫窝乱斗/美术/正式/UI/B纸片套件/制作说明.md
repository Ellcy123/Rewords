# B 纸片 UI 套件

用户于2026-09-29授权按试接按钮制作全部UI，要求先生成示意图并考虑配色。

先产出 `00_配色示意图.png`，工具为Codex内置imagegen。此图只表达视觉方向，不作为切图资产，也不覆盖现有玩法/角色定义。示意中的鱼/猫图标只用于展示格子，正式组件不添加这些图标。示意图中的生成文字不作为程序文字。

配色：奶油纸 #F3ECD9、沙色衬纸 #D8C8A8；主操作琥珀 #F2C35D、赭橙衬纸 #C9823E；次操作灰蓝 #B8CCD0、蓝灰衬纸 #6F8F99；深棕描边/文字 #3E3029；我方生命鼠尾草绿 #79A28D；敌方生命砖红 #BA5D50；禁用灰 #CDCBC4。

生产覆盖：主次按钮、窄按钮、禁用/按下状态、信息薄面板、详情/结算/弹窗面板、商品卡/待放格及选中框。用少量独立无字九宫格组件复用所有尺寸，不逐控件生成整张图；文字、生命条、棋盘网格及动态数值继续由程序绘制。保持当前布局、命中矩形和玩法。

原始风格必须沿用B纸片拼贴：切角、简练深棕墨线、双层错位纸片、大面板局部折角，禁止满屏纹理、圆润塑料按钮、猫爪/星星装饰。按下通过独立前后纸层收拢，文本随前纸移动。审查由Luna/xhigh，单项三次失败停止重做。

## 源图与接入

示意图Luna/xhigh审查PASS。大面板的衬纸统一为沙色，不扩充示意图偶然出现的浅珊瑚色。

内置imagegen分别制作了两张无字、独立纸层：`button_layer_source.png` 与 `panel_layer_source.png`。其底色为中性白，Unity用统一色板着色，而非生成多个略有偏差的颜色版本。原图保留有效alpha，不重复抠图；打包仅裁透明外边和等比采样，没有程序重画造型。提示词分别保存在01/02文本文件。

- `paper_strip.png`：切角无折角，PPU200，九宫格左右36、上下16源像素。复用于所有长短主次按钮、商品卡、待放格、顶栏、怪物名、提示和详情面板。
- `paper_panel.png`：左上局部折角，PPU200，九宫格左64、下32、右40、上48源像素。用于结算和确认弹窗。
- 前后纸层是两个独立Image，普通态相差3逻辑像素；按下时前纸及文字移动2像素使错位收拢，根点击矩形不动；禁用改灰并将前纸向后纸靠近1像素；键盘选中用琥珀背纸提示。
- 字体继续Noto Sans SC，颜色深棕。商品图和商品文案跟随前纸一起运动；禁用不影响文案可读性。
- 棋盘格、生命条、冷却条、拖拽/命中区、现有猫与怪物仍保留程序绘制或原美术资产。生命条统一到色板的绿色/砖红，不为7像素高的填充条生成贴图。

已接入正式工程的UiFactory/PaperUi；这表示当前玩法界面所有常用表面均由该套件覆盖，不代表新增未策划的首页、局外商城或其他功能。实际测试和视觉验收见 `美术/审查/Unity/B纸片全套/`。
