# A_轻手绘

工具：Codex 内置图像生成；状态：风格探索，未定稿。

Use case: ui-mockup
生成《猫窝乱斗》竖屏二维手绘游戏的一张 UI 美术样板，正方形画幅，展示可实际拆分制作的界面组件。面向广泛年龄玩家，可爱有设计感，不低幼。
统一构图：顶部仅写版本字母“A”；上半部是一个宽信息面板，含空白标题区、安静的正文留白和右上角关闭叉；中部横排三个尺寸相同的主按钮，分别展示普通、按下、不可用状态，各放同一个简洁三角播放符号，不写文字；底部横排四个等大的物品格，分别为空、选中空格、简单鱼形图标、简单软猫侧面剪影图标。物品格不加复杂装饰。清楚网格排布，组件之间充足留白，纯净展示底，不画卧室、手机外壳或人物。
状态差异以厚度、位移、边框和符号清晰度呈现，不只依赖颜色。保持文字安全区平整干净。无文字段落、无数字、无水印。配色自行协调，不预设具体色相。不要做商业应用仪表盘或写实材质。

设计方向：轻手绘。细而坚定的墨线，边缘轻微自然起伏；略方的圆角矩形，少量不对称转角作为记忆点。面板薄边框，按钮仅短而干净的块面投影，物品格保持规整。气质清爽、聪明、克制，家具插画旁也不抢画面。

美术风格提示词：
stylized 2D hand-drawn game UI artwork, economical confident ink outlines, subtly irregular outer contours, controlled consistent border weight, clear simple silhouettes, clean flat fills, restrained planar shading, minimal surface rendering, generous quiet interiors, coherent corner shapes, clear visual hierarchy, crisp readability at small scale, understated playful character, no preschool picture-book aesthetic, no decorative clutter, no all-over grain, no soft-focus glow, no airbrushed gradients, no plastic gloss, no photorealistic materials, no 3D rendering
