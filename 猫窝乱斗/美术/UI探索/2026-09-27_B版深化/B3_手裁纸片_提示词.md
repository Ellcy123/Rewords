# B3_手裁纸片

工具：Codex 内置图像生成。参考图：../2026-09-27_三版/B_纸片拼贴.png；用户已选 B 家族，当前变体待选。

Use case: ui-mockup
以所附 B 版 UI 图为唯一参考，为《猫窝乱斗》生成同一家族的 UI 变体样板。必须继承 B 的切角、局部折角、错位纸片层次和手绘墨线，不改成圆润漫画或软糖 UI。
保持正方形样板排布：上部一块宽信息面板，空标题区和空正文区，右上关闭叉；中部三个同款播放按钮，普通、按下、不可用状态；底部四个同尺寸物品格，空、选中、鱼图标、猫图标。三个按钮宽度、切角规则和播放符号尺寸一致，按下态通过底层错位收拢表示，不仅换色。四个物品格形状一致。文字仅顶部的版本标识，不画其他标签。
参考图的配色关系仅用于本轮控制变量，尽量保持一致，不重新探索颜色；这些颜色不是通用画风要求。不要添加猫耳、爪印、星星、漂浮短线等装饰。展示底统一干净浅色，无手机外壳、场景或真实物体。内部留白宽松，组件完整。二维插画平涂为主，阴影用窄小实色块，减少渐变、高光与纹理，绝不写实纸材质。

具体设计：
顶部版本标识为“B3”。手裁纸片方向：保留 B 的纸片家族，让切角大小稍有不对称，长边有极轻微的手裁倾斜、线条自然粗细变化，大面板保留左上一处俏皮折角。底层衬纸仅轻微斜置，前层文字和图标区域仍端正平整。三按钮同一外形，不各自随机扭曲。更有独立游戏的手作个性，成熟克制，不做破纸、锯齿、胶带、脏污或幼儿手工拼贴。
