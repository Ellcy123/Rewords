# 年糕猫六帧呼吸试验

用户授权使用 video-motion-design-enhancer 的动作设计方法尝试 Codex 直接出帧动画。该 skill 负责动作设计；图像由 Codex 内置图像生成制作，不调用视频生成。

交付：原始 3×2 六帧图、等格切出的单帧 PNG、循环 GIF 预览及帧时长记录。采用纯白背景先看动作，不在本轮解决抠图和正式 Unity 导入。不修改现有角色原图。

动作目的：懒散贴地的猫自然呼吸，腹背缓慢起伏。使用缓入缓出、局部体积保持和稳定轮廓；不加入其他表演，以隔离逐帧一致性问题。6 帧一轮，暂定约 2 秒，首尾接近而非额外复制首帧。固定头、脚、耳、尾、镜头；主要风险是锚点漂移、斑纹变化、全身缩放和纹理闪烁。

这是生成稳定性探索，不宣称可直接量产或已实现游戏动画。

## 实际图像提示词

Use case: stylized-concept
以所附年糕猫为角色参考，制作一张真正用于逐帧动画的六帧 sprite sheet，不是六个不同的猫设定。画布横向3:2，严格3列2行等分、六格无间隙，每格相同正方形。阅读顺序左到右、上到下。每格恰好一只完整猫，姿态均为朝左趴地；角色长轴水平。所有格的猫头、鼻尖、前爪、后爪、尾尖在格内位置完全对齐，大小一致。猫占单格宽度82%，脚底基线位于格内高度78%，全部尾巴胡须均不越界。背景为完全均匀纯白，无格线、文字、编号、标记、阴影、地面、纸纹背景。
动作设计：6帧是一轮柔和的腹式呼吸，猫保持懒散贴地、头部和前爪承重不动。F1呼气末放松原姿；F2轻轻吸气，只有肩后至臀前的腹背上缘抬升很少；F3继续吸气，腹背缓慢隆起；F4吸气峰值，比F1背线抬升约单格高度的3%，仍是横长软猫，不变胖成球；F5平缓呼气，回到F3与F2之间高度；F6接近F1，只残留极微隆起，之后能顺接F1。缓入缓出，无突然跳动。体积基本守恒，腹部接地轮廓固定，不要整只缩放。不要眨眼、转头、抖耳、摆尾或移动四肢，这些局部在六帧严格相同。
角色保持：完全继承参考图的年糕体型、左耳竖起右耳折下、左眼闭合右眼半睁、三花斑块的形状和位置、尾巴卷曲轮廓、爪子数量、原配色。斑块只能随局部呼吸微微形变，不能每帧重新随机画。墨线和纹理跨帧保持一致，主体保留原图二维手绘干笔质感，但不要随机新增毛丝、颗粒或明暗。不重新设计，不变成3D、矢量图、软糖或另一只猫。
六帧是几乎一致的同一张角色图，只允许腹背呼吸处的少量变化。优先画布和落脚点一致，其次运动幅度。
