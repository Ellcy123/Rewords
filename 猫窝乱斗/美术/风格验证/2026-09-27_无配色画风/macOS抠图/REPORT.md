# macOS 原生抠图检查

## 工具与步骤

- 环境：macOS Sequoia 15.4.1（Build 24E263）。源图均为 1536×1024、RGB PNG。
- 使用工具：Finder（`com.apple.finder`）右键图片 →「快速操作」→「移除背景」。在输出目录的副本上分别执行，未调用 Vision API、第三方抠图服务或手工修补。
- Finder 输出未经优化的 RGBA PNG，画布保留为 1536×1024。原文件未覆盖；`A_年糕猫_原生结果.png` 和 `B_闹钟怪物_原生结果.png` 是放在本目录的原图副本，Finder 结果是下列“已移除背景的…”文件。
- 对比图由 Swift/AppKit 只做确定性 Alpha 合成，分别放在白、黑、洋红底；没有改动抠图结果。

## 输出

- 猫：`已移除背景的A_年糕猫_原生结果.png`
- 怪物：`已移除背景的B_闹钟怪物_原生结果.png`
- 全图三底对比：`A_年糕猫_full_compare.png`、`B_闹钟怪物_full_compare.png`
- 局部对比：猫的 `A_年糕猫_detail_whiskers.png`、`A_年糕猫_detail_folded_ear.png`、`A_年糕猫_detail_tail_inner_gap.png`、`A_年糕猫_detail_ground_shadow.png`；怪物的 `B_闹钟怪物_detail_teeth.png`、`B_闹钟怪物_detail_fingers_left.png`、`B_闹钟怪物_detail_fingers_right.png`、`B_闹钟怪物_detail_thin_legs_gaps.png`、`B_闹钟怪物_detail_ground_shadow.png`。

## 观察到的结果

- 猫：胡须线、折耳轮廓和尾巴内空仍可辨；尾巴内空已透明。细胡须和外轮廓在黑/洋红底上有浅灰暖白的边缘晕。贴地投影基本被移除，只剩贴地轮廓线。
- 闹钟怪物：尖牙、两只手的指爪间隙及细腿/肢体空隙大体保留，局部没有看到明显的大块主体误删。细腿、爪尖周围有可见的浅色晕边。地面投影基本被移除。
- 两张结果 Alpha 统计（RGBA 1536×1024）：猫透明像素 1,051,340、半透明 47,118、不透明 474,406；怪物透明 1,121,643、半透明 140,661、不透明 310,560。统计仅描述像素，不单独作为质量通过依据。

## 判断

- 以上是局部与全图预览中的直接观察；“不适合作为最终游戏资产直接导入”是基于边缘晕在深色/彩色底上可见、且贴地投影丢失的判断。轮廓和主要细节可用作自动抠图初稿，但若游戏需要干净透明边缘和接地感，还需独立处理边缘及投影。
