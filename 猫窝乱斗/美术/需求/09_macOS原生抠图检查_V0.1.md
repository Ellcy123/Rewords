# macOS 原生抠图检查

用户要求：对无配色画风试稿的年糕猫和闹钟怪物，使用 Mac 自带抠图工具，实际检查边缘是否不干净、有残留。原图不修改。

输入：`美术/风格验证/2026-09-27_无配色画风/A_年糕猫.png`、`B_闹钟怪物.png`。

执行与检查按项目规定交给 GPT-6 Luna / xhigh 子代理。优先系统界面移除背景；如使用 Apple 原生 Vision API，需清楚注明实现路径，不把 API 调用冒充 Finder 操作或声称两者结果必然相同。禁止生成式重绘、第三方抠图模型及未经说明的人工修边。

保留未经修边的自动抠图 RGBA PNG。对比底色图仅通过确定性合成生成，不改变 Alpha。重点观察猫的胡须、耳尖、尾巴内空、贴地阴影，以及怪物尖指、细腿、肢体间空隙和阴影；分别记录背景残留、边缘光晕与主体误删。

输出放在原批次目录下的 `macOS抠图/`，附方法说明、预览和短报告。此操作不涉及 Unity 导入，不能将能抠出主体等同于正式游戏资产验收通过。
