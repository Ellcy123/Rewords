# 程序 UI 替换

2026-09-28 用户明确要求 UI 先用程序 UI，不再使用资产 UI。

当前界面使用 Unity Image/Text/Button 绘制纯色面板、细格线和按钮。按钮使用 ColorTint 区分普通、按下和禁用；主操作按钮采用深绿色和白字，其他文字采用深色。选中格为暖黄，连接格为浅绿。空待放区显示用途提示。

猫、用品、梦魇和背景继续使用现有 Sprite。旧 ui_ PNG 保留作历史资料，运行中的界面不再引用。此前纸片界面的 PASS 只反映当时的有限检查，不能作为视觉质量认可；本轮以实际程序 UI 截图和可读性复核为准。

验证：Luna/xhigh 在临时工程副本使用 6000.4.0f1 完成 EditMode 17/17、PlayMode 5/5 和新 macOS Player 构建。实际 540×942 首屏显示纯色面板、细格线、加粗深色文字；旧 UI Sprite 无运行引用。

截图：`美术/审查/Unity/program_ui_first_stage.png`。来源为独立构建 `CatGame-Programmatic-UI-QA` 的真实窗口（540×970 含标题栏，客户区540×942）；早先来源不明首屏和系统弹窗截图均作废，未采用。

验证边界：自动交互测试通过；CUA 手动点击未触发选中与弹窗，原因未确认，不能声称该两项原生鼠标操作已验证通过。本轮没有以测试通过替代整体美术质量认可。

存档：两个现有存档均已恢复，SHA-256 与测试前一致。
