# 出图需求：前三关梦魇正式资产 V0.1

状态：制作中。日期：2026-09-27。

## 1. 策划依据与共同边界

- 具体身份与外形来自 `09_前3关关卡设计_V0.1.md`：床底的手、倒走闹钟、衣柜长影。
- 第 1 关：床下伸出的扁长影手，手指像拖鞋的轮廓。
- 第 2 关：表盘歪斜、长着两条细腿，指针倒转。
- 第 3 关：从半开衣柜里折出来的过长人形影子，无写实人体细节；画面体积可以更大。
- 三者前三关均只有普通攻击，不把额外技能或状态画进基础图。
- 熟悉物件或形状通过比例、姿态与动作异常产生怪诞感；不做血腥、尖牙怪物或写实恐怖。
- 每个梦魇先制作一张完整透明基础图；待机、攻击、受击、消散首轮通过 Unity 图层位移、缩放、扭曲与透明度完成。
- 最终 PNG 长边不超过 800 px，四周保留 7%–9% 透明安全区。

## 2. 床底的手正式外形

- 轮廓：一条贴地、扁长、像墨影被压扁的前臂，从狭窄床底暗缝中伸出。
- 手掌宽而低，五根手指清楚但不写实；每根指端都像软塌拖鞋，圆钝、略向外撇。
- 方向：从左侧暗缝向右前方爬出，便于攻击时做短促前探。
- 色彩：深靛蓝／炭灰为主体，边缘有少量褪灰蓝平面色块与一点旧赭色反光，不能是一整块死黑。
- 性格：第一关威胁较弱，别扭、可笑、稍微不安；不画血、指甲、骨骼或写实皮肤。

## 4. 审查上限

- 每个梦魇独立累计失败次数；第三次 FAIL 后停止重做，保留最佳版本并记录遗留问题。
- 静态审查通过后，仍需在 Unity 战斗区域内检查尺寸、遮挡、攻击位移、受击反馈和消散效果。

## 6. 倒走闹钟正式外形

- 一只日常圆形双铃闹钟发生比例异常：表盘整体歪斜，两条细长腿从钟壳底部伸出。
- 指针明确呈逆时针关系，但基础静态图不画旋转轨迹；倒走动画由 Unity 旋转独立指针层或整体轻微回摆表现。
- 怪诞来自歪表盘、过细长腿和别扭站姿，不增加尖牙、手臂或额外技能。
- 配色与床底影手区分：褪旧赭黄钟壳、暖纸白表盘、深靛指针与腿、少量珊瑚红校时钮。

## 9. 衣柜长影正式外形

- 从一条半开衣柜门缝中折出来的过长人形影子，整体像被反复折叠的纸影或布影。
- 身体比例明显异常：小而无五官的头、极长躯干与四肢、折角式肩肘膝；不出现写实肌肉、手指和人体皮肤。
- 一只脚／下摆仍接在柜缝内，身体向战斗区前倾；攻击可通过上身短促折叠前探实现。
- 第三关画面体积最大，但仍只有普通攻击，不画 Boss 光环或额外技能。
- 配色：深蓝黑主体、褪紫灰平面层次、少量旧木赭色柜缝边缘和冷纸白轮廓反光。
