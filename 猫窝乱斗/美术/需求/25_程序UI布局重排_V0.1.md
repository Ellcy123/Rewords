# 程序 UI 布局重排

2026-09-28，用户授权使用项目内 game-ui-frontend 重排布局。沿用 Unity Canvas/uGUI；不引入浏览器界面、不更换玩法或数值。

## 本轮实现

- 顶部收为一条关卡与资源信息。暂停在战斗时显示，重开在准备和结算时显示。
- 敌人在上方卧室中独立展示，取消白色头像卡；生命条在头顶，并有受击缩放反馈。
- 420×420 猫窝保持可操作面积，位置下移，为敌人留出空间。准备、战斗、结算维持棋盘位置。
- 准备阶段底部展示待放物、三件商品和开始守梦。商品图加大；刷新、视频奖励为次要入口。
- 旋转、姿势、收回、出售按选中物件显示；扩容仅在原本允许的关卡出现并显示价格。详情可关闭。
- 战斗时隐藏待放与商店，以战斗状态和倒计时替代常驻日志；结算显示下一夜或重试入口。
- 连接生效后收起常驻教学提示。不把此前提出的百分比草案作为固定规则。

## 验收

由 gpt-6-luna / xhigh 执行测试和画面审查。需要准备、战斗、结算及第三关敌人画面；检查棋盘操作、主按钮、敌人轮廓和文字可读性。同一失败项三次不通过后停止重做并如实列出。

功能回归：Luna / xhigh 已完成 EditMode 17/17、PlayMode 5/5。新增阶段布局测试首次因正常战斗夹具在 3 秒尚未结束而失败，改为既有快速战斗夹具后通过；没有修改玩法数值。测试覆盖准备/战斗/结算主要区块、商店收起、购买拖放及四关推进。自动输入不代表真实触摸验证。
