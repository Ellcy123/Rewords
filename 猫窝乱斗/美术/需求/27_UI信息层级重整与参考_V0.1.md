# UI 信息层级重整与参考

2026-09-29。用户反馈字体太细，要求参考网上IAA游戏，重新考虑按钮数量/排版，并明确说明文字与按钮应有不同UI。用户随后明确“开始修改”，本方案已进入正式工程实现。

## 已确认问题

1. 字体文件不是预想的常规体：读取NotoSansSC.ttf的OS/2 weight为100，fvar的wght范围100–900、默认100。上轮直接使用Normal导致极细字，不能仅归因于字号或截图。
2. PaperUi.StylePanel把HeaderPanel、EnemyLabel、HintPanel、WaitingArea等均用与按钮相同的切角纸片、暗描边和后纸。非交互信息看起来可以点击。
3. 初始准备态显示三个商品卡，但仅一个有商品，两个“后续开放”仍为大号禁用卡；底部刷新、视频金币、开始并列，低频重开常驻。问题是视觉权重与重复占位，不是应删除所有操作。
4. 上轮审查证明功能正常/无遮挡，不能据此判定整体设计合格。用户已否定字体与信息层级，应重新验收。

- [Backpack Brawl 官方站](https://www.backpackbrawl.com/)与[MiniReview实玩页](https://minireview.io/auto-battler/backpack-brawl)：已打开其商店/背包截图。商店物品以图像和小价格牌展示；Fight主按钮、Info/Reroll小按钮、Gold状态标签外观/位置明确分工。此作是构筑布局参考，不作为纯IAA商业化证据。

商店宣传图可能含营销排版，桌面/主机截图不能直接当作手机IAA模板。当前结论来自上述具体界面，不意味着所有IAA游戏采用同一套排版。

## 新方案（助手建议，保留玩法与B风格）

|区域|显示内容|表现方式|
|---|---|---|
|顶部轻HUD|夜数、金币、生命/盾、菜单|数字/小标签，不围成四个按钮；重开收进菜单，战斗保留明确暂停入口|
|上方怪物区|怪物本体、名称与HP|继续保留Boss空间；名称与血条合组，去掉名称按钮皮肤|
|中央棋盘|猫、物品、连接反馈|保持最大主要区域；不增加厚框|
|棋盘边缘提示|当前一步操作/选中物说明|单层平面纸条，无后纸、无按压造型；只出现当前需要的提示|
|下方商店|实际可购买物品、价格、刷新|卡片表现为商品；不画未开放空槽；刷新紧贴商店并仅在可用阶段出现|
|底部主操作|开始守梦；结算时下一夜|唯一强琥珀双层纸片按钮，独立一行；不与广告/刷新争同等权重|
|奖励入口|视频补金币|归入金币补给区域，保留视频与奖励标识及足够触控区域，不伪装普通加号或强迫广告|
|待放区|已购待放物品|有物品时显示托盘；为空时不常驻“新的一夜开始了”大框，重要反馈以短提示呈现|

战斗态不常驻大块“守梦中/猫咪正在保护梦境”解释面板，保留计时与战斗反馈；胜负后才出现结算面板和下一步操作。选中物品时才显示旋转/姿势/收回/出售等情境工具，保证功能可发现。

第一关目标是一个明确主按钮、一个实际商品，以及弱化的资源补给/菜单入口；高级关卡仍可显示多个商品，但与操作按钮分组。这里减少的是无效控件和视觉噪声，不改商店商品数、金币奖励或核心操作规则。

字体选明确静态500正文、700标题/主要按钮；具体文件接入后以实际中文截图确认，不仅设置枚举值。主要操作20–22、正文18左右，密集数值16–18，按照真实面板容量确定，不使用极细体。

## 实施与验收顺序

先重新画准备态的信息层级示意图，包含真实文字与第一关仅一个商品的状态；再实现准备/战斗/结算，不直接重生成全部美术。现有B按钮和折角弹窗可复用，薄信息底板单独处理。Luna验收除功能外，必须验证静态文字能否一眼区别于可点击操作、主操作是否突出、字体是否清楚；手机比例截图不称为手机真机验证。

## 已实施的第一轮

- 字体从项目原始Noto Sans SC可变字体导出静态500/700实例，重命名为Cat UI Medium/Bold并附原OFL。正文与按钮使用明确字体文件，FontStyle保持Normal，不再依赖合成加粗或默认100实例。原字体不删除。
- 说明/状态为平面无描边底板，商品为单层平面卡片，按钮才保留错位纸层。大确认弹窗/结算仍复用折角纸张，维持B风格。
- 顶部显示夜数/生命/盾，菜单中包含返回与重新开局；战斗时保留直接暂停。金币移至商店资源行，视频入口仍明确显示奖励，刷新仅在可用时出现。
- 商店只显示有商品的货位，按1/2/3个实际商品居中；无商品时简短提醒“用品已备齐，布置好后开始守梦”。主按钮为底部420×52独立一行。
- 待放托盘仅有物品时出现，购买后仍可拖入棋盘；商店为其让出位置。棋盘420×420与Boss位置保留。
- 待放物品使用左图右文200×40条目（图58×34，名称18号），支持多个条目横向滚动，不再缩成20像素高的小图。
- 战斗摘要改为单行计时，结果出现后才显示大面板。操作反馈短暂显示三秒；拖拽中不因提示到期销毁界面。
