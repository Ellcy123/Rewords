# Unity 竖屏临时资源需求 V0.1

日期：2026-09-25；2026-09-26 更新：占位实现扩至四关，改为 uGUI，并加入三猫六用品、连接高亮、拖放合法性颜色、冷却／技能计数和分段数字反馈。具体测试由独立报告确认。正式画风未定，本文件的颜色和图形不作为正式风格母版。

## 目标

先在 Unity 6+ 跑通 09 的前三关与 11 的第 4 关：买入 → 拖放 → 连接 → 自动战斗 → 奖励 → 下一关。支持鼠标调试，保留触摸操作适配。直接使用 Unity 图形与文字，不另做网页版本。

## 竖屏布局建议

以 1080×1920 为布局参考，不锁死实际屏幕分辨率；按安全区域与可用高度适配。

- 顶部：金币、关卡与战斗计时，控件避开系统安全区。
- 上部：梦魇、敌方生命条、攻击表现。
- 中下部：方形猫窝、我方生命与护盾、连接提示；棋盘必须保持方形，扩容不能把格子压成矩形。
- 底部：准备时显示三槽商店、待摆区与开战按钮；战斗时收起购买控件，给猫窝和战斗反馈留空间。
- 选中猫时在棋盘外显示旋转、姿势按钮，避免手指遮住目标格。
- 小屏优先收缩装饰区，不靠缩小文字与按钮硬塞。具体尺寸以 Unity 实际拖动体验调整。

格子碰撞与技能来自配置，不能依赖临时图片透明像素。用品图标与场内表现复用；猫姿势换图时同步真实轮廓。选中、可放、冲突、有效连接分别有线框或符号提示。

## 此阶段保留的体验

- 拖动吸附、无效落位回退、旋转和换姿势可用。
- 有效连接立刻亮起，显示加成来自哪件用品。
- 攻击间隔改变可感知；三次普攻的技能触发、追击来源清楚。
- 购买、过关、失败状态明确，计时与动画互不驱动。
- 占位资源集中引用，后续可替换外观，不重写技能、棋盘与商店逻辑。

暂不制作正式字体体系、插画背景、批量猫姿势或精细动画；临时资产可以粗糙，但交互反馈不能省掉。本文件不构成已经跑通或完成测试的证明。

## 本轮实际交付边界

当前用原生 UI 色块、文字、进度条与数字变化。还没有制作爪痕、鼠影、护盾动画或音效；这些属于后续手感／美术工作，不能用数字反馈冒充正式表现完成。中文字体已接入可分发的 Noto Sans SC，随工程保存 OFL 许可证。未调用 Midjourney 或 image2。
