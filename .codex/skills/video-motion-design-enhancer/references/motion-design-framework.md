# 视频动作设计框架

## 1. 动作增强顺序

按以下顺序思考，再写成连贯的导演指令：

1. **继承条件**：镜头编号、时长、画幅、输入图角色、人物与场景设定、已有时间码。
2. **动作目的**：镜头结束时观众应看懂什么、感受到什么。
3. **不变量**：身份、服装、道具、构图、空间方向或光线中必须稳定的部分。
4. **动作节拍**：准备、主动作、动作峰值、跟随、收势。
5. **主体表演**：重心、受力、动作弧线、视线、表情和速度变化。
6. **镜头运动**：最多一个主要方向，并说明它如何服务主体动作。
7. **环境响应**：与主体、风、接触或镜头变化有因果关系的次级动态。
8. **退出状态**：为尾帧或下一个镜头留下明确姿势、朝向、动量和道具状态。
9. **风险约束**：最多 3–5 项当前最可能出现的问题。

静态画面已经清楚的内容只需简短继承，把提示词篇幅留给什么要动、如何动、何时动以及如何停下。

## 2. 经典动画原则的可观察表达

不要把原则名称直接堆进提示词。选择与当前动作有关的原则并转译：

| 动作需求 | 优先原则 | 可观察的动作语言 |
|---|---|---|
| 起跳、冲刺、挥击 | 预备动作、弧线、时间控制、缓入缓出 | 先压低重心蓄力；身体沿清晰弧线发力；启动短促，落地回弹后稳定 |
| 柔软、弹性、碰撞 | 挤压与拉伸、扎实造型、时间控制 | 接触瞬间轻微压缩，离开时适度拉伸；保持总体体积、关节和轮廓可信 |
| 转头、挥手、走路 | 弧线、重叠动作、跟随动作 | 头部和手臂沿自然弧线；发梢、衣摆和饰品晚半拍跟随并逐渐停下 |
| 情绪与微表情 | 舞台调度、夸张、吸引力、次要动作 | 先用视线引导注意，再改变眉眼和嘴角；以呼吸、手指或姿态补充情绪 |
| 环境动态 | 次要动作、重叠动作、缓入缓出 | 动态从触发源传向近景、中景和远景，各层延迟、幅度和速度不同 |
| 首尾姿势衔接 | 关键姿势、预备动作、时间控制 | 建立起始、中间和目标姿势；每次重心转移都有准备、受力和收势 |
| 产品或静物展示 | 舞台调度、弧线、缓入缓出、扎实造型 | 主体轮廓清晰；镜头沿单一路径移动；比例、材质和标签稳定 |
| 舞蹈或节拍动作 | 关键姿势、时间控制、夸张、跟随动作 | 在明确节拍形成可读轮廓；动作峰值命中时间锚点，肢体与衣发随后释放惯性 |

夸张程度服从项目风格：写实镜头使用轻微形变、克制表情和可信受力；卡通镜头可以放大预备姿势、轮廓和节奏反差，但仍保持体积与重心一致。

## 3. 输入模式

### 精准首帧

把图片视为视频的准确起点。开头可写：

```text
将图1作为精准首帧，保持人物身份、造型、服装、配色、场景构图和光线方向一致。
```

不要要求第一帧出现图片中没有的预备姿势；预备动作应从现有姿态自然开始。

### 仅作参考

明确图片负责锁定人物、服装、道具、场景或视觉风格中的哪一项，不要求第一帧复刻原图，也不要笼统写“参考图片”。

### 首尾帧

明确图1是首帧、图2是目标尾帧。比较两帧的主体位置、姿势、重心、视线、表情、道具、镜头位置和环境状态，把差异拆成中间关键姿势。开头短暂停留以建立起点，结尾留出约 10%–20% 时长减速并稳定贴合尾帧。

不要使用溶解、闪白、遮挡、瞬间变形或无理由切镜代替真实衔接，除非这就是用户指定的转场设计。

### 无图片或已有提示词

可以直接增强。保留用户已经确定的主体、动作目的、镜头、风格和时长；对无法从文本确定的视觉细节不要擅自补写。

## 4. 时间结构

优先服从用户给出的时间码。没有时间码时，使用相对阶段，避免为了套模板强行改变镜头时长。

### 简单动作参考

- 前 15%：建立姿势、视线和预备动作。
- 15%–65%：完成主要动作，表现路径、受力和速度变化。
- 65%–85%：跟随动作、反应与环境反馈。
- 后 15%：缓出、收势并稳定退出状态。

### 小情节参考

- 前 15%：建立主体、情绪与空间关系。
- 15%–30%：事件触发或预备动作。
- 30%–70%：主动作与情节变化。
- 70%–90%：反应、跟随与环境反馈。
- 后 10%：收束在清晰姿势或目标尾帧。

这些比例是起点，不是硬规则。快速剪辑、节拍命中、长停顿或突然中断可以改变比例，但动作峰值和退出状态仍须清楚。

## 5. MV 时间锚点

当已有时间码或节拍说明时，把动作写成“锚点 + 可见事件”，例如：

```text
00:12.000 开始侧身蓄力；00:12.750 在重拍完成转身并形成清晰剪影；00:13.200 衣摆和发梢释放惯性；00:13.800 收稳视线，为下一镜头的正面近景留下匹配姿态。
```

遵守以下规则：

- 动作峰值可以命中重拍，但准备动作必须提前发生。
- 剪辑点附近要么形成清晰关键姿势，要么保留明确动量供下一镜头承接。
- 歌词节点只控制已提供的表演意图；不要从歌词自行扩写新的剧情。
- 口型、舞蹈编排和音频分析需要上游提供结果；本框架只增强其动作可读性和连续性。

## 6. 多镜头状态交接

逐镜保留以下最小状态：

| 字段 | 内容 |
|---|---|
| 进入状态 | 姿势、朝向、视线、动量、道具手位、环境状态 |
| 动作峰值 | 镜头最清晰的关键姿势及其时间锚点 |
| 退出状态 | 最终姿势、朝向、剩余动量、表情、道具和环境状态 |
| 下一镜继承 | 必须延续或有意改变的项目 |

匹配剪辑应保持运动方向、屏幕轴线和动作相位。跳切或蒙太奇可以有意破坏连续，但要由既有剪辑意图驱动，而不是动作增强器自行添加。

## 7. 通用模板

模板只提供结构，应删除无关内容。

### 单图或文生视频

```text
【继承参考图角色或既定设定】。生成【时长】秒【单镜头／镜头编号】视频，动作目的为【目的与情绪】。开始时【主体】先【视线／重心／预备动作】；随后沿【方向与弧线】完成【主要动作】，速度由【变化】、受力点位于【位置】，在【时间锚点】形成【关键姿势】。【表情和视线】随动作变化；【发梢／衣摆／道具／环境元素】由【触发原因】晚半拍响应，并以不同速度逐渐停下。镜头【一个主要运镜或保持稳定】，始终让动作轮廓清晰。最后【收势和退出状态】。保持【关键不变量】，避免【当前风险】。
```

### 首尾帧

```text
图1作为精准首帧，图2作为目标尾帧，保持【身份、服装、道具、空间和光线】连续。开头从图1姿势自然产生【预备动作】，随后通过【关键姿势1】和【关键姿势2】，沿【动作路径】完成【主动作】；每次重心转移都有明确受力和速度变化。【表情、视线和次级动态】按情节逐步变化。镜头【主要运镜】，保持空间方向。最后在【时间范围】减速进入图2的构图、姿势、表情和环境状态，并稳定贴合尾帧。全过程不使用突变、遮挡或突然切镜跳过中间动作。
```

## 8. 交付前检查

- 是否保留了已有剧情、镜头顺序、时间码和视觉设定？
- 动作是否有清楚的准备、主动作、峰值、跟随和收势？
- 路径、重心、受力与速度变化是否可信？
- 动画原则是否已转成可观察语言？
- 运镜是否服务动作，而不是与动作争夺注意力？
- 环境动态是否有触发源、延迟和空间层次？
- 首尾帧是否通过真实动作衔接？
- 多镜头的进入与退出状态是否能够承接？
- 是否只列了当前最重要的稳定性约束？
- 输出是否是完整新版，而不是要求用户自行拼接的补丁？
