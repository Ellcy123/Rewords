# 《未能输出》16 型人格“人格权柄”能力表 V2.0

> 版本：V2.0 第二轮重构<br>
> 核心要求：无启动前置、一句话看懂、猎奇而直接、强到足以制造神性优越感<br>
> 设计变化：删除上一轮的五米范围、次数限制、局部信息与平衡优先

## 1. 新能力标准

### 1.1 能力不是提示器，而是权柄

不再设计“能看见一点别人看不见的信息”，而要设计“能直接决定某类现实如何存在”。

合格能力必须满足：

- **直接**：一句话使用“回档、转移、实现、删除、重组、改写、征收”等强动词；
- **强大**：普通人无法用常规手段与之对等，持有者确实拥有傲慢的资本；
- **无前置**：不需要触碰、口令、同意、蓄力、材料、关系或特殊情绪；
- **猎奇**：能力生效时有肉体、尸体、虫群、剥皮或世界畸变等鲜明画面；
- **对应人格**：不是给 MBTI 贴职业标签，而是把其认知偏好推到“我有资格统治这一领域”；
- **一句话懂**：第一次听见就知道这个人能做什么，不用先学习操作说明。

### 1.2 不再追求平衡

本轮不设置统一距离、次数、持续时间、冷却或代价。能力可以读取、控制、复活、回档、修改因果甚至制定物理法则。

戏剧张力改由三件事承担：

1. 十六种权柄彼此冲突；
2. 持有者的人格盲点会让“最强解”变成“最坏解”；
3. 能力能决定事实，却不能证明持有者的价值判断正确。

## 3. 十六句“一眼就懂”版本

- **ISTJ·世界存档**：把全世界回档到他保存过的任意时刻。
- **ISFJ·伤命转移**：把任何伤病和死亡转给任意一个人。
- **INFJ·梦境降临**：把任何人的梦永久变成现实。
- **INTJ·未来删改**：删除所有不满意的未来，只留下一个结局。
- **ISTP·万物拆装**：把任何东西拆掉，再重组成他想要的形态。
- **ISFP·永恒标本**：让任何事物永远停在她认为最美的一刻。
- **INFP·比喻成真**：让自己认定的比喻全部按字面成真。
- **INTP·因果改写**：替换一个原因，让整个现实重新计算结果。
- **ESTP·死亡回档**：每次死亡都让世界倒回死前，而且只有他记得。
- **ESFP·情绪支配**：随意改写一个人或一群人的情绪。
- **ENFP·愿望实现**：让任何人的愿望立即成真。
- **ENTP·概念盗窃**：从人或世界里偷走任意一个概念。
- **ESTJ·绝对法则**：她定下的规则会直接成为物理法则。
- **ESFJ·关系改写**：任意改写两个人的关系、感情和共同记忆。
- **ENFJ·人格塑造**：把任何人改造成自己认定的理想人格。
- **ENTJ·万物征收**：把任何东西划为己有并绝对控制。

## 4. 人格对应原则

能力与人格不是“爱修理所以会修理”的职业映射，而是认知方式的神化：

- **SJ** 获得保存、承担、立法和维系关系的绝对权；
- **SP** 获得重组物质、冻结审美、征服死亡和操纵现场的绝对权；
- **NF** 获得实现梦境、具现意义、实现愿望和重塑人格的绝对权；
- **NT** 获得删改未来、重算因果、盗取概念和征收世界的绝对权。

判断能力是否真正匹配人格，只问一句：

> 这个人拥有它十年以后，会把自己误认为哪一种神？

若答案只是“一个很好用的超能力者”，设计仍然不够；答案必须是历史之神、牺牲之神、梦境之神、未来之神、结构之神、永恒之神、意义之神、因果之神、死亡之神、情绪之神、奇迹之神、概念之神、法律之神、关系之神、人格之神或所有权之神。

## 5. 禁止回退

后续扩写不得重新加入：

- 五米范围、每日一次、十秒消失等统一平衡阀；
- “只能看见但不能改变”的信息型弱化；
- 必须触碰、说口令、取得同意或建立关系的启动仪式；
- 为了给玩家留反制而临时增加的物理漏洞；
- 只有猎奇外观、实际效果却不痛不痒的能力。

角色仍然可以失败，但失败原因应优先来自另一项同级权柄、错误的价值判断、信息误导或本人不愿违背的执念，而不是能力突然没电。
