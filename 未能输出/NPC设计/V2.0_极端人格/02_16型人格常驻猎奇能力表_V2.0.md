# 《未能输出》16 型人格常驻猎奇能力表 V2.0

> 版本：V2.0<br>
> 核心要求：无启动前置、自动存在、一句话看懂、猎奇但不全知<br>
> 使用方式：本表完全替换 V2.0 早期沿用 V1 能力的方案，不修改或删除 V1 文件

## 1. 统一能力规则

### 1.1 什么叫“没有前置条件”

角色不需要主动发动能力，也不需要：

- 触碰或握手；
- 说出口令；
- 取得对方同意；
- 先建立关系；
- 先满足某种情绪；
- 等待目标睡着、进食或作出承诺。

NPC 出现在场景中，异能便自动存在。伤口、机器、说话或工作等只是异象表现的对象，不是 NPC 必须完成的启动仪式。

### 1.2 统一范围

除“蜕命”只作用于本人外，其余能力默认作用于 NPC 周围五米。

目标离开范围十秒后，能力制造的临时异象消失；已经造成的普通物理后果不会倒退。

### 1.3 统一平衡原则

- 一项能力只制造一种核心异象；
- 能力可以暴露局部事实，不能解释完整动机；
- 不直接控制思想、情绪、选择或忠诚；
- 不因为猎奇视觉获得无限治疗、无限杀伤或完整预知；
- 玩家能通过离开范围、遮挡、记录、制造对照或拒绝接受角色解释进行反制。

## 3. 一眼测试

每项能力只保留一个最强画面：

- 伤口开口；
- 伤势复制；
- 梦变尸体；
- 手心说出被删掉的话；
- 机器长脏器；
- 遗物孵人脸蛾；
- 比喻长到身上；
- 人被因果脐带连接；
- 从自己的尸体里蜕生；
- 情绪变虫；
- 愿望变狗尾；
- 借口吐出小人；
- 违规让骨头增生；
- 腹部长出思乡的嘴；
- 被利用的方式长成肉瘤；
- 干活时背上长出工作手。

若对白必须先解释两条以上隐藏规则，能力便不合格，应继续简化。

## 4. 猎奇感分工

十六项能力不能全部只是“看见信息”。它们分为四类：

### 4.1 身体作证

- 伤口嘴；
- 代伤；
- 败嘴；
- 比喻病；
- 违规骨；
- 家口。

身体把人不愿面对的事实直接暴露出来。

### 4.2 异物寄生

- 梦尸；
- 遗物蛾；
- 情绪虫；
- 愿望尾；
- 借口人；
- 用处瘤。

抽象关系变成甩不掉的生物或器官。

### 4.3 机械肉化

- 机器脏器；
- 工作手。

效率与功能被直接翻译成肉体，方便制造劳动、修理和利用人的对白。

### 4.4 因果与死亡异常

- 因果脐；
- 蜕命。

一个把变化来源变成脐带，一个把死亡变成可以脱下的外壳。

## 5. 禁止回退的设计

后续扩写不得重新加入以下启动方式：

- “只有触碰后才能……”；
- “对方必须主动说……”；
- “只有真心笑时……”；
- “需要先握手、吃饭、阅读或讲梦……”；
- “每次使用前必须选择目标并念出口令……”；
- “必须关系达到某个阶段才能生效……”。

次数、范围与时长可以存在，但它们只能限制能力，不能把一句话能力变成操作说明书。

## 6. 与 V1 的关系

V1 继续作为第一轮能力设计档案保留；V2 不继承其能力，只继承以下经验：

- 能力需要客观边界；
- 玩家必须能验证与反制；
- 能力不能直接读取完整人格和唯一真相；
- 对白趣味来自角色如何误解能力，而不是能力替剧情回答一切。

V2 的正式扩写应以本表为能力来源，以《16 型人格极端执念原型表 V2.0》为人格来源。
