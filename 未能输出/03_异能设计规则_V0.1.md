# 《未能输出》异能设计规则 V0.1

> 当前状态：已确认的 NPC 异能准入规则
> 适用范围：所有 NPC 的单一异能、首轮原型与后续关卡设计
> 核心目标：异能应创造可推理的信息差，而不是替玩家完成推理或解决问题。

## 1. 总原则

本作的异能不是“更强的角色能力”，而是一条可被玩家逐渐掌握的信息规则。

每项异能都必须同时满足：

1. **一句话可懂**：不看设定说明，玩家也能用日常语言复述它大致能做什么。
2. **只给一种事实**：它只扩展一个明确的信息维度，不同时给出事实、动机、情绪和未来。
3. **边界比效果清楚**：玩家应当更容易说出“它不能知道什么”，而不是只记得它很厉害。
4. **不能代替出牌**：异能提供线索，功能卡与玩家判断才决定怎样利用线索。
5. **不能代替关系**：它不能自动获得信任、消除伤害、说服对方，或让角色理解情感。

一句话判断：

> 如果玩家拿到异能信息后，只要选一张明显正确的卡就能结束对话，这项异能就是超模的。

## 2. 简单易懂的设计标准

### 2.1 一句能力定义

每项异能必须能写成以下句式，且不需要附加条件才能理解主体效果：

> 当【触发条件】发生时，他/她能准确知道【一种可观察的信息】。

合格示例：

- 只要亲眼见过或亲耳听过，他能准确回溯最近 60 秒发生的内容。
- 触碰物件后，他能准确知道把它修好的方法。
- 在短时间内观察过一个人后，他能列出其接下来三种行为的概率。

不合格示例：

- 他能看透别人真正的想法、秘密与未来。
- 她能感知一切危险并给出最好的解决方案。
- 他能理解别人没有说出口的情绪。

这些说法同时混合了多个信息层级，玩家无法知道能力究竟输出了什么。

### 2.2 单一输出原则

一项异能只能稳定输出一种信息形式：

- 已发生的外部事实；
- 当前可测量的状态；
- 被明确限制的短时预测；
- 某一类物件的操作方法；
- 一句已形成但未发送的文字。

它不能同时输出两种以上形式。例如，能回溯行为的角色不能因此知道谎言动机；能看见未发送文字的角色不能因此知道对方是否真心；能预测行为的角色不能因此知道行为的情感原因。

### 2.3 一个主要限制

每项异能必须有一个玩家可在剧情中验证的主要限制。限制可以来自：

- 对象：只对自己见过的人、只对物件、只对发给自己的信息；
- 时间：只看最近 60 秒、只预测下一次短时行动；
- 触发：必须接触、必须在场、必须有已知行为样本；
- 精度：只给趋势、片段、三种分支，不能给完整解释；
- 内容：只能确认发生了什么，不能确认为什么。

限制不能只写在角色背景中；首轮对白必须至少一次让玩家因为它而修正判断。

## 3. 防止“超模”的硬性约束

### 3.1 异能不能输出结论

异能只能给原始信息，不能直接回答关卡要问的问题。

| 关卡问题 | 允许的异能信息 | 不允许的异能信息 |
| --- | --- | --- |
| 他为什么取消见面？ | 他最后一次编辑又删除的消息 | “他因为害怕见你才取消” |
| 这句话是不是谎言？ | 此前发生的具体行为、当前生理趋势 | “这句话是谎言” |
| 要不要继续追问？ | 对方对互动的接近/回避趋势 | “追问一定会成功” |
| 这个物件能否修好？ | 修复方式或不可修复的事实 | “修好它就能解决你们的关系” |

### 3.2 异能不能跨越人物边界

异能不得直接读取或决定以下内容：

- 深层动机、人格本质、道德好坏；
- 完整记忆、所有秘密、未形成的想法；
- 必然未来、唯一正确选项、关卡最优解；
- 他人对主角的信任值、好感值或最终关系结局；
- 情绪应当如何被处理的答案。

若能力涉及思想、情绪或关系，只能读取一个极窄、可重复验证的表层信号，且必须保留多种解释。

### 3.3 异能不能替代行动成本

即使玩家已经获得可靠事实，仍必须承担至少一种成本：

- 信息不完整，必须继续验证；
- 出牌可能损害关系或关闭信息出口；
- NPC 可以拒绝解释、结束对话或要求对等暴露；
- 事实与动机之间仍存在推理跳跃；
- 玩家需要在有限轮次中取舍。

“知道”不能自动等于“说服”“修复”“原谅”或“成功”。

### 3.4 异能不能覆盖全部场景

每个 NPC 的异能都必须有其天然无效区。关卡应刻意安排至少一种：

- 异能没有触发条件；
- 关键变量不在异能对象或时间范围内；
- 异能输出正确，但存在至少两种合理解释；
- 玩家若过度依赖异能，会造成关系判断失误。

## 4. 单角色异能规格模板

所有新 NPC 在进入完整角色文档前，先填写以下九项。任何一项不能明确回答，均不得进入关卡制作。

| 字段 | 必须写清的内容 |
| --- | --- |
| 一句话能力 | 触发条件＋唯一输出 |
| 核心对象 | 人、物、文本、行为或一种状态 |
| 时间范围 | 当前、固定时长、短期下一步等 |
| 输出精度 | 数值、片段、趋势、固定数量分支等 |
| 玩家可见表现 | 玩家从何种异常中发现能力 |
| 主要盲区 | 它绝对不能读取或判断的内容 |
| 常见误读 | 玩家最容易把事实误解成什么结论 |
| 三张卡的差异 | 至少三种功能卡为何会产生不同后果 |
| 失效场景 | 哪一种关卡情境下，它无法提供关键答案 |

## 5. 关卡验收门槛

一项异能可以进入首轮原型，必须同时通过以下五项检查：

1. 玩家在第一次异常出现后，能提出正确的能力假设；
2. 玩家在第二次验证后，能确认其核心范围；
3. 至少一次，玩家会因误把“事实”当成“动机”而受到合理反馈；
4. 至少三张功能卡面对该 NPC 有不同收益与代价；
5. 关卡结算能指出：玩家是没发现信息、误读信息，还是为关系代价作了选择。

若不能通过，优先删减能力效果，而不是继续添加例外和补丁。

## 6. 常见超模信号与处理方式

| 超模信号 | 为什么有问题 | 收缩方式 |
| --- | --- | --- |
| “总能知道真相” | 消灭了推理空间 | 改为知道一个可验证事实 |
| “能读心” | 同时获得情绪、动机、秘密与意图 | 仅读取一条已形成的表层文字或一个状态信号 |
| “能预测未来” | 容易变成最优解提示 | 只给短时、有限分支的行为概率，并要求已有样本 |
| “能感知关系” | 容易直接替代关系系统 | 只给互动后的接近/回避趋势，不给原因和结果 |
| “碰到就知道一切” | 对象范围与信息量都失控 | 只知道一种操作方法或一段固定时长的外部事实 |
| “能力失灵是反转” | 让玩家无法建立规则 | 能力始终准确；出错只能来自范围外或解释错误 |

## 7. 现有三名 NPC 的适配检查

### ISTJ「事实回溯记录员」：通过

- 一句话能力明确：回溯自己亲历的最近 60 秒事实。
- 输出单一：外部行为与原始措辞。
- 主要盲区明确：动机、未见内容和更早历史。
- 关卡重点应始终落在“事实正确，不代表解释正确”。

### ISTP「修理者」：通过，但须保持物件边界

- 一句话能力明确：触碰物件后知道修复方法。
- 输出单一：修复方法或不可修复的事实。
- 不得把“知道怎么修”扩展为自动取得工具、修复人或解决关系。
- 关卡重点应始终落在“问题可修，不等于对方想被修”。

### INTP「行为概率演算者」：条件通过，需严格控制预测范围

- 一句话能力明确：给出短时行为的有限概率分支。
- 为避免成为万能预知，预测必须基于已观察到的行为样本，且只覆盖下一次短时行动。
- 输出不得解释动机；最高概率不得被写成必然结果。
- 关卡重点应始终落在“预测对了行为，不代表理解了原因”。

## 8. 新角色设计的执行顺序

新增 NPC 时，固定按以下顺序推进：

1. 先写一句能力定义和主要盲区；
2. 用九项规格模板检查范围；
3. 写三段验证能力边界的对白场景；
4. 再写人格伤口、关系变化和完整角色文档；
5. 最后才决定是否纳入首轮原型。

这条顺序的目的，是防止先写出很有魅力的角色，再为了保留设定而不断把异能做大。

## 9. 最终判断

> 好异能不是让玩家觉得“他什么都知道”，而是让玩家觉得“我终于知道他能看见哪一块，却仍要自己决定这意味着什么”。
