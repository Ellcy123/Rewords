# 猫神町 · 七日疑案 Demo

当前版本：`0.7.0-sunset-case`。React 网页客户端 + Fastify 权威状态服务 + DeepSeek。
本章改为“被当成自杀结案的杀人案”，不再执行旧失踪案的零号站台事件。

## 运行与验证

使用 Node.js 24（本机验证版本 24.11.0），在本目录执行：

```powershell
npm install
npm run dev
```

网页：http://127.0.0.1:5173/

健康检查：http://127.0.0.1:8787/api/health

```powershell
npm test
npm run build
npm run record:dialogues
```

最后一条命令对七人分别记录开场与一次选项回复，使用独立内存存档，不改网页进度。
输出在 `../对白测试记录/<时间戳>_杀人案重构抽样.md`。保留真实生成、回退和材料读取结果，不包含密钥或隐藏推理。
`record:natural` 是同一新版记录器的别名。旧记录器源码和 `*.legacy.ts` 测试只保留作历史参考，不再作为当前入口执行。

## 当前可玩内容

- 七名 NPC、八个地点、18 个物品定义：5 件日常物品、11 份初始案件材料、2 份条件生成说明。
- 初始地图仅有神社、车站、商店街。实际播放的对白／实际读到的材料说出地点，才显示地图节点。
- 已知地点没有门禁。进入地点不会自动开始会面；同场多个人物分别点击；无人地点照样可以探索。
- 移动一小时，交谈或确认赠礼两小时；礼物选择和取消不计时。场景可等待半小时，长时间等待逐节点处理事件。
- 短选项、主角与 NPC 共用对白节拍、“下一句”逐句播放并保存。一次会面最多24句显示对白（含主角），约18句进入收尾，最多5次玩家选择；随时可以提前结束。
- 前向分支对话：AI 根据本段末尾生成 2～3 个短回应，不再从固定话题池挑选。选择后不补发本次会面中错过的选项，允许自然收束。
- 查看、出示、索要、赠送分别处理。材料进手记不代表拿到实物，送出后手记保留。所有持有物品均可赠送或供奉。
- 夜间一次信仰／审美改写，公共规则进入存活 NPC 的记忆与对话，不改历史事实。
- 第七天结束生成结局与七人状态结果；AI 不可用时有事实保底，不因缺证卡关。
- 首条自主事件链：千代改口 → 可写说明或主动联系别人 → 律实际收到消息 → AI 选择接触／威胁／袭击／放弃 → 按时间与在场情况处理。
- 可在接触前、威胁阶段、袭击中或事后抵达旅馆。现场干预、离开、实际求助产生不同结果。死亡不凭空掉落遗书或补发证据。

## 初版边界

目前只有“千代改口”这一条完整高风险行动链，不是所有角色均能任意杀人的沙盒。
行动时间按游戏时钟推进，不按现实等待推进。其他人物不会被每晚强制轮换地点。
反思暂用会面实际见闻摘要；长期记忆按相关性、近期性、重要度检索，并非完整复现研究系统。
AI 文案校验不能等同于中文语义的绝对正确；固定材料与执行状态由系统保持权威，文学表现继续通过记录器检验。
对白和结局在结构校验后增加一次独立事实审校调用，不通过则重试或保底；这会增加一次模型请求和少量等待时间。它不能保证中文语义零错误。
美术仍为既有占位资源，本次不新增图片、不迁移 Unity。

历史版说明见 `README_旧章节参考.md`；案件设计依据见上级目录 08～11 号文档。

## 前向对话测试

提示词版本：`sunset-v4-graceful-conversation`。规则见上级目录 `12_前向分支对话规则_V0.1.md`。
现有存档兼容，不必重新开始；已经显示的旧选项不会被后台改写，下一次生成开始使用新规则。

```powershell
$env:CASE_RECORD_NPCS='npc_koharu,npc_chiyo'
$env:CASE_RECORD_ROUNDS='4'
$env:CASE_RECORD_FOLLOW='1'
npm run record:dialogues
```

`CASE_RECORD_FOLLOW=1` 自动优先选不执行物品动作的问句，只用于抽样，不影响游戏选项。
可设 `CASE_RECORD_DRAFTS=1` 附加生成草稿和审校结果（含失败候选，不能当作已发生剧情）。
记录使用内存存档，每段保留完整对白、全部选项、实际选择和错过的回应。未到收尾阶段的真实AI续聊连续失败时，报告可重试错误，保留原节点，不伪造NPC告别；已到会面预算上限才允许保底收尾。未配置AI的离线演示仍使用mock。

会面收尾专项：`npx tsx scripts/recordClosingDialogue.ts`。使用明确标注的构造前文，将预算设为已说18句，真实调用模型检查最后一段是否符合人设并结束。不是完整实玩长流程记录。
预算根据本次会面已播放事件重建，刷新和重启后不清零；显示完收尾对白后只可返回场景，不能通过出示材料／转告消息续聊。
约14句或第4次选择开始预告收尾，18句／第5次选择进入告别阶段。最后通常用2～4个节拍先回应、接住情绪，再收拾东西告别，不强迫一句话打断。
只读重放最近一次玩家选择：`npx tsx scripts/replayLastChoice.ts`，在内存副本中生成，不回写游戏。可用来区分“AI正常决定结束”和“技术失败误结束”。
