# 《猫神町》网页 Demo

当前版本：`0.3.0-day3`

这是《猫神町》一周 Demo 的 Day 3 版本。移动、会面、物品、规则、跨日与单存档已经连通；水野纱夜已接入 DeepSeek 结构化对白，其余 NPC 继续使用固定 Mock，对话接口失败时会自动回退且不阻塞玩法。

## 当前可用内容

- 固定主角“朝雾遥”：21 岁旧物整理员、猫神社七日代理管理人；
- 顶部与背包页显示主角公开身份、私人目标和起点谜团；
- 三地点地图：猫神社、猫神町站、镜庭商店街；
- 地图不显示 NPC 头像，进入地点后才确认在场角色；
- 每天使用 `09:00～18:00` 的连续时钟；移动花费 1 小时，完整会面花费 2 小时；
- 到达后直接离开只消耗移动时间，不消耗交谈时间；
- 抵达地点和开始会面是两个独立步骤：先查看场景与在场人物，再主动点击人物；
- 会面开始时选择“交谈”或“赠送礼物”；
- 交谈可通过选项获得物品，赠礼会永久转移物品并进入礼物专属对话；
- 水野纱夜使用 8 层版本化 Prompt、四轮戏剧场景、JSON Schema、事实 ID 和选项 ID 白名单；
- 选项式对话，不包含自由文字输入；
- 一段交流可包含 2～5 个 NPC／主角交替台词节拍，途中使用“下一句”推进，到真正的决策点才显示选项；
- 六件物品、六个承载概念和两个世界规则槽的数据；
- 背包只显示简单物品名，不提前显示承载概念；
- 神社白天可预览；18:00 入夜后可修改一次规则或跳过；
- 跨日推进与 SQLite 单存档，刷新网页不会恢复已经转移的物品；
- 顶部常驻“重新开始”入口，并在清空七天进度前进行二次确认；
- 世界状态、物品所有权、事件日志和脱敏 AI 调试页；
- 前后端共享 Zod Schema；
- 数据契约、Provider、Prompt 和核心状态机自动化测试。

## DeepSeek 本地配置

在 `server/.env.local` 中配置，文件已被 Git 忽略。不要把真实密钥写进源码、文档或提交记录。

```dotenv
DEEPSEEK_API_KEY=填写本机密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
```

未配置密钥、请求超时、接口异常、空响应、JSON 解析失败或白名单校验失败时，水野纱夜自动使用固定保底对白。当前模型名是本地评测配置，不属于业务逻辑常量，可通过环境变量更换。

## 当前边界

Day 3 已接通：

- `地图 → 抵达地点 → 点击人物 → 选择会面方式` 的独立状态流；
- 水野纱夜的普通交谈、赠礼开场与赠礼追问均由真实 DeepSeek 生成；
- 首次交谈包含四轮态度选择，纱夜会根据关心、逼问、玩笑、欺骗、坦白或站队作出不同回应；
- 纱夜首次见面会自然自我介绍并确认朝雾遥的公开身份，后续见面不重复互报姓名；
- NPC 台词负责引导选择，按钮只显示不超过 10 个汉字的短表态，不再附加意图说明；
- 每个短选项确定朝雾遥的起始发言与后续语义边界；点击后双方可以自动交替说话，直到下一决策点；
- 固定人设、知识边界、当前世界状态、相关事件、会面模式与选项白名单分层组装；
- AI 只生成台词、情绪和选项文案，不能直接修改物品、时间、奖励和世界规则；
- 交谈路线的异常车票奖励仍由服务端根据固定选项 ID 结算；
- Provider 最多尝试两次，15 秒超时，失败后使用 Mock 保底；
- 调试页只保存请求结果、耗时、次数、事实 ID 与错误码，不保存密钥、完整 Prompt 或隐藏推理。

其余两名 NPC、结构化长期记忆和完整世界规则 callback 仍属于 Day 4 范围。
