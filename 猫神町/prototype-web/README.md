# 《猫神町》网页 Demo

当前版本：`0.6.0-agent-rewrite`

这是《猫神町》一周 Demo 的 Agent 对话重构版。玩家可以从第一天完整推进到第七天；三名 NPC 围绕“雨宫真昼在零号站台失踪”这一具体案件交锋，赠礼、证物、世界规则、人物行动与跨日记忆会共同进入结局事实摘要，再由 DeepSeek 生成结局；接口失败时使用同一批事实生成固定保底结局。

## 当前可用内容

- 固定主角“朝雾遥”：21 岁旧物整理员、猫神社七日代理管理人；
- 顶部与背包页显示主角公开身份、私人目标和起点谜团；
- 三地点地图：猫神社、猫神町站、镜庭商店街；
- 地图不显示 NPC 头像，进入地点后才确认在场角色；
- 每天使用 `09:00～18:00` 的连续时钟；移动花费 1 小时，完整会面花费 2 小时；
- 可以在地图直接“等待入夜”，不会被迫通过无意义移动耗尽时间；
- 七天各有一条公开事件、目标提示和明确的 NPC 地点作息；
- 到达后直接离开只消耗移动时间，不消耗交谈时间；
- 抵达地点和开始会面是两个独立步骤：先查看场景与在场人物，再主动点击人物；
- 会面开始时选择“交谈”或“赠送礼物”；
- 交谈可通过选项获得物品，赠礼会永久转移物品并进入礼物专属对话；
- 三名 NPC 共用 `agent-dialogue-v3` 分层 Prompt，具备公开面具、具体目标、恐惧、底线、错误信念、秘密、语言指纹与动作偏好；
- 对话以雨宫真昼、黑色单程票、零号站台、通行令复写纸、刻名猫铃和未裁切照片组成同一条案件证据链；
- 每个场景节拍由系统指定目标与合法行动 ID，模型负责人物化表演，服务端校验并记录真正执行的 NPC 行动；
- 短期会面上下文、长期 Memory Stream、相关记忆检索、会面反思与次日计划彼此分离；
- 选项式对话，不包含自由文字输入；
- 一段交流可包含 2～5 个 NPC／主角交替台词节拍，途中使用“下一句”推进，到真正的决策点才显示选项；
- 六件物品、六个承载概念和两个世界规则槽的数据；
- 六件物品均有实际获取路线，全部可以赠送或作为任一规则槽的载体；
- 背包只显示简单物品名，不提前显示承载概念；
- 神社白天可预览；18:00 入夜后可修改一次规则或跳过；
- 跨日推进与 SQLite 单存档，刷新网页不会恢复已经转移的物品；
- NPC 跨日更换地点，并可转赠已经收到的物品；
- 小春公开寻亲、纱夜交出证据、弦一推动第二次神隐及第七天零号站台对峙组成一条可追踪的关系链；
- 每名 NPC 独立保存带 `source_event_id` 的结构化记忆、关系与规则回调；
- 顶部常驻“重新开始”入口，并在清空七天进度前进行二次确认；
- 世界状态、物品所有权、事件日志和脱敏 AI 调试页；
- 前后端共享 Zod Schema；
- 数据契约、Provider、Prompt 和核心状态机自动化测试。
- 第七天结束时冻结状态，生成主结局、三名 NPC 后日谈、收束句与赠礼／规则事实回收卡；
- 结局 Prompt 只接收结构化事实 ID，失败时不会卡住通关。

## 本地启动

环境要求：Node.js 20 或更高版本。

```powershell
cd D:\Rewords\猫神町\prototype-web
npm install
npm run dev
```

## DeepSeek 本地配置

在 `server/.env.local` 中配置，文件已被 Git 忽略。不要把真实密钥写进源码、文档或提交记录。

```dotenv
DEEPSEEK_API_KEY=填写本机密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
```

未配置密钥、请求超时、接口异常、空响应、JSON 解析失败或白名单校验失败时，对应 NPC 自动使用角色专属保底对白。当前模型名是本地评测配置，不属于业务逻辑常量，可通过环境变量更换。

## 记录真实对白基线

在本机已经配置 DeepSeek 后，可重复运行固定的 16 条测试行程，并生成不包含密钥、完整 Prompt 或隐藏推理的纯对白记录：

```powershell
npm run record:dialogues
```

当前重构记录输出位于 `../对白测试记录/2026-09-03_Agent重构完整行程.md`。旧版 Day 5 基线保留用于前后对照。记录器覆盖 24 个固定交谈选项、6 件赠礼物品，以及一次跨日记忆与世界规则回访，并额外记录场景目标、NPC 行动、记忆候选与反思候选。

生产客户端构建输出到 `dist/client`。
