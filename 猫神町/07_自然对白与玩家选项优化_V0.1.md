# 自然对白与玩家选项优化 V0.1

更新时间：2026-09-05。当前运行提示词：`agent-dialogue-v4.2-natural`。

本版保持 DeepSeek、本地配置、现有世界观和剧情状态机不变，调整对白写作方式与选项展示。本文与早期 AI NPC 文档冲突时，以本版本的具体实现说明为准。

## 写作重点

- 先回应玩家此刻实际说的话，再处理 NPC 眼前想做的事。不拿另一段案情代替回答。
- 取消每句至少 15 字、每轮至少两类具体信息、最多一个问号等硬性文风限制。允许短反应、停顿、改口和必要的完整说明。
- 小春急于让人认真听，嘴硬后会补救；纱夜习惯先处理手边的事，省字但不写公文；弦一保持礼貌并试图谈条件，避免反派演讲。
- 中文示例放在 `server/src/prompts/dialogueVoice.ts`。开场使用 NPC 单方样例，选择后才给双人接话样例，避免开场替玩家决定态度。
- 示例只示范表达，不能写进人物历史。允许当下低风险姿态，不允许编造人物往事、证据、承诺或神迹。
- 普通赠礼可以只是好意。礼物所有权仍按原系统结算，不强迫所有礼物与真昼案件相关，不擅自达成恋爱、交换或保密约定。

## 提示词输入

1. 硬边界：世界事实、已允许披露的秘密、物品所有权、当前选择的后果。
2. 人物：当下想法、精简行为核心、中文语气示例。
3. 现场：时间地点、规则、当天事件、当前场景动作。
4. 连续经历：真实对白及可见动作、相关长期记忆、现有反思。
5. 玩家关注：上一句原文、已听到的内容、之前的实际经历；后台知道不等于玩家知道。
6. 本轮选项的语义边界及输出契约。

## 短选项与玩家台词

选项 ID 和剧情后果仍由程序管理。模型根据刚生成的对白，在各 ID 的语义范围内写 2～12 字短选项；服务端不再把合格文本覆盖成旧模板。

每个选项提供一个 `anchor`，摘录本段 NPC 台词或动作的原文，用于确认它至少指向当前展示过的内容。锚点不展示给玩家。

关键行动保留目标词和行动词检查，例如“去找纱夜”须让玩家看见对象和行动，不能把“弦一为什么给票？”结算成同意去找弦一。

点选后的第一句直接使用短选项原文。后续仍支持主角与 NPC 交替说话，原有“下一句”界面不变；主角不得自动增加承诺、交物、站队或接受风险。

**本版不是无限动态分支。** 候选意图、决策次数和主要案件推进仍然沿用现有状态机；锚点及关键词是基础校验，不能证明所有选项都符合玩家真正的关注点，也不能完整判断句子语义。需要继续人工试玩验证。

## 连续性与异常处理

- 对话事件现在保留可见动作，下一轮能够承接动作，不仅能看见台词。
- 记忆记录实际展示过的说话和动作，并标注“某人说”，不把内部写作指令或未展示的知识复制为已发生事实。NPC 说过的内容不因此变成世界真相。
- 现有反思仍是轻量模板，本版没有声称实现完整 Generative Agents 反思和自主规划。
- 不再裁掉中间对白或截断长句来凑长度。输出不符合契约时重试一次，并提供具体校验提示；仍失败就使用保底对白。
- 开场生成未授权玩家台词会重试，不能删去玩家台词后留下 NPC 对不存在问题的回答。
- 调整了过宽的“回头/眼神”词语拦截，允许当下普通动作，继续阻止提前透露真昼最后留言。

## 验证与复测

执行 `npm test`、`npm run build`，再执行 `npm run record:natural`。

实测使用独立内存存档，不读取或重置网页存档。脚本走三人首见和连续选择、小春次日重访与“土豆是神”、三人收到土豆并回应普通赠礼心意，共 17 次独立对白请求。

每次运行用时间戳创建新的原文记录，保留失败和保底输出，不覆盖既有基线，也不重复计数同一段对白。记录不包含 API Key。

人工复核项目：中文是否自然、是否真接上前一句、选项是否重复问已知问题、短句与后果是否一致、角色有没有编造往事、结束时是否留下无法回答的新问题。

## 当前仍需观察

本轮迭代样本中，普通收礼更容易出现简短的感谢和试探；但案件对话仍有菜单式引导、额外补写过去细节、重复催促玩家同行等现象。固定剧情动作也可能与当前地点或玩家期待不完全匹配。不能把通过结构校验或没有回退当作中文质量已经合格。

初次样本为 V4，第二次为 V4.1；最终版本 V4.2 针对开场角色混用、内部策略出现在选项中、关键行动选项含糊等问题继续收紧。各版本的完整模型原文保留在“对白测试记录”文件夹，供下一次试玩对照。

### 本轮验证结果

- 40 项自动测试通过；类型检查与生产构建通过。
- V4.2 的 17 次独立对白请求中，16 次返回 DeepSeek 对白，1 次因输出结构不合规进入保底。没有把重试或同一段对白重复计数。
- 最终原文：`对白测试记录/2026-09-05T04-01-59-651Z_自然对白V4实测.md`。
- 样本仍出现未设定的猫铃制作经历、收礼后重复问动机、已在车站却提议去车站等内容。这些是明确保留的质量问题，后续需针对事实依据、当前地点和场景收束继续评测；本次没有把它们自动改写成“合格”记录。
- 本地网页已经启动。已有会面显示的旧对白不会被重写；结束当前会面，再开始一次交谈或赠礼即可使用新版，无需清空存档。
