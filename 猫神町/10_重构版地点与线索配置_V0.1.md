>
> 案件依据：《08_自杀结案的杀人案_完整真相与人物知情关系_V0.1》。人物依据：《09_重构版七人正式角色卡_V0.1》。本文新增配置 ID 与具体来源，不更换凶手，不更改案发时间线。

## 1. 初版范围

八个地图地点、七名主要 NPC。沿用旧原型三个地点 ID，新增五个。地图仅有 `discoveredLocationIds`，发现后即可前往；没有钥匙、许可、开放时段、封锁状态、通行等级。

人物作息改变谁在场，不改变能否进入。地图只显示地点，不显示 NPC 头像或隐藏角色位置；到达后显示实际在场人物，玩家再决定与谁交谈。移动和交谈仍分别耗时，进入场景不自动开始交谈。

下文“拒绝交物”“不愿作证”都是人物行为，不能变相成为关闭地点的条件。

“典型在场者”是生活据点，不是任意时刻必在的承诺。任务事件完成后应记录角色去向，不能离开又被下一句对白放回原地。

### 五个新地点的发现来源

| 地点 | NPC 可能主动提起的理由 | 至少一条替代来源 |
| --- | --- | --- |
| 白石旅馆 | 律介绍千代，或解释自己声称当晚在哪里 | 小春谈起真昼原信收件人；纱夜提起千代 |
| 猫神町警署 | 小春不满结案，提到犬饲 | 桐生解释自己的记录交到了哪里 |
| 桐生诊所 | 纱夜建议核对医生究竟写过什么 | 犬饲交代报告来源；千代谈起桐生 |
| 雨宫家旧居 | 小春说明委托整理的东西还有一部分在家 | 千代说明真昼搬走前的安排，但不替小春编造额外钥匙 |
| 夕见台 | 小春实际说出姐姐死亡地点 | 律谈报道、犬饲解释案情、千代纠正见人回来的方向 |

AI 选择何时谈及这些内容，不预先固定在哪一轮解锁；但涉及其中地点的关键调查话题应有至少一个现存 NPC 能谈，不能全员永久回避。

### 发现的一致性

- NPC 在已展示台词里说出明确地名，立即触发发现。仅说“一个地方”不触发。
- 别名如“警署”“白石家的旅馆”只映射到已定义地点，不生成新地点。具体别名词典在实现时集中维护。
- 拒绝、警告或争吵中的地名同样有效。不能把“不要去夕见台”当成未发现。
- 玩家实际读到的固定材料、实际展示的场景文字若明确提供同一地点，也应同步发现，避免“玩家已经知道，地图却装不知道”。NPC 决定是否展示材料，仍是重要信息来源。
- 初始三点指任何开场信息展示之前；如果开场已明确说出夕见台，地图当时就应增加它，不能为了保持三个点而无视文本。
- 后台人物行程、秘密、候选台词、未播放到的下一句不触发发现。案件攻略文档中出现地名也不算游戏内发现。
- 一次发现只结算一次，并给简短提示。地点一经发现不回退；NPC死亡不删除地图点。

## 4. 线索载体与所有权

先配置 11 件固定案件材料、2 件可能在本章形成的新说明。普通物品仍另行配置，总物品规模维持约 30 的方向，不把每一句证词都做成新背包物品。

| ID／短名称 | 开局实体及持有人 | 取得／阅读方式 | 对应内容与限制 |
| --- | --- | --- | --- |
| `E01`／车票 | 一份两张票的组合物品；小春持有 | 小春可先展示，再自行决定是否交出；玩家明确收下才转移 | `F02`。两张票同次购买、分别属于姐妹；不证明死亡方式 |
| `E02`／旧报 | 商店街公开样张摊有一份留给读者的报纸 | 在现场选择阅读或取走，非 NPC 在场要求 | 已刊发的捐款指控与遗书摘录；读到不等于相信其内容 |
| `E03`／信 | 千代持有真昼原信 | 对话展示／交付；若她离场仍保留其所有权，不自动出现于桌上 | `F05`。完整四句，不能生成新留言 |
| `E04`／审稿页 | 九条持有、案发后留存的审稿材料 | 九条愿意澄清摘录来历或与律切割时可展示／交付 | 显示全文曾经进入审稿材料，不直接证明谁杀人 |
| `E05`／值班页 | 纱夜保管的原始相关页 | 核对争执时间时展示；转交是另一个决定 | `F04`，九条在站的时间；不能编造监控影像 |
| `E06`／值班抄件 | 开局已经在警署卷宗里的既存抄件 | 提出具体时间矛盾后由犬饲展示／交付；不是原件丢失后复制出来 | 与 `E05` 同源，不能当成第二名独立证人 |

| `E08`／旧稿 | 商店街公开样张夹里留有一份律的旧稿样张 | 可现场阅读／取走，不需要记者陪同 | 能核对撰稿人、标题修改与引用；没有“凶手自白”或凭空留下的完整犯罪记录 |
| `E09`／录音卡 | 雨宫家旧居的遗物箱内，开局固定存在的录音副本 | 地点已发现后可到遗物区观察、读取、收取；不需要钥匙、设备购买或密码 | `F12/F03`。仅包含不实报道委托谈话，没有死亡现场录音 |
| `E10`／检查记录 | 桐生保管、仅含本案必要信息的记录 | 桐生可解释、展示或交付；无关医疗隐私不进入故事文本 | `F07`。不能推导具体凶手或补写法医数据 |
| `E11`／检查副本 | 警署既存案情副本 | 与犬饲核对摘要时展示／交付 | 与 `E10` 同源；对照摘要的失真，不是独立医学鉴定 |
| `E12`／纠正说明 | 开局不存在；千代决定作证后才形成 | 显式“写下并确认”事件生成一份，初始由千代持有，再按交付事件转移 | 记录她改口的具体内容，支持 `F06`；不能在她死亡后补生成 |
| `E13`／补充说明 | 开局不存在；犬饲决定纠正公开结论后才形成 | 显式发布事件生成，记录当时可支撑的结论 | 不能因为作者知道真凶，直接写“律杀了真昼” |

材料短名称用于背包。复杂的疑点写入详情与调查记录，不把名字写成“被恶意截断且能证明某人说谎的关键原信”。物品映射到信仰、审美概念时继续使用已有物品概念机制，不直接把后台事实 ID 当成神谕。

### 固定引用

`E02` 中作为遗书刊出的两句：

> “我不想再这样过下去了。明天开始，别再来找我。”

`E03/E04` 的完整四句：

> “我不想再这样过下去了。明天开始，别再来找我。我要带小春离开猫神町，等住处定下来，再把地址寄给你。”

`E09` 可播放的关键片段，作为本次材料细化固定下来：

> 真昼：“钱根本没丢，你为什么这么写？”
>
> 律：“九条让我这么写的。他要你回来道歉，稿费也是他给的。”

这段录音是案发前的谈话，不包含约见夕见台、推落声或临终指认。听到录音可以质疑律的诚实与动机，不能让旁观者自动拥有原案目击记忆。

### 口头线索与现场观察

- **千代口头纠正：** 可先发生，不一定写成 `E12`。记录谁亲耳听到；遥再转告犬饲是另一条事件。
- **姐妹争吵、纱夜拒绝离町：** 属于人物经历披露，不额外生成实体物品。
- **夕见台观察：** 让玩家理解道路方向与视野；从旅馆看到有人从那个方向回来不等于看到推落。初版不新增指纹、血迹、武器等一碰就确定真凶的物证。
- **次生冲突目击：** 记录玩家何时在哪里看见哪些动作，与原案 `F08` 分开；不能通过目击律威胁千代就声称看到了三周前杀人。

## 5. “看过”“拿到”“相信”是三件事

这不是新的地点准入系统，而是已有物品与知识逻辑的区分。

1. 展示材料：玩家获得其可见内容，物品仍在原持有人手上。
2. 转移物品：必须有具体实例与实际交付事件；拒绝交付不能抹除玩家已经看过的内容。
3. 解释材料：NPC 可以怀疑、否认或撒谎；调查记录保留来源，不自动采信最后一句话。

所有实体物品都可以赠送。拿到重要信件后再送给律，是玩家真实选择，不弹“关键道具无法赠送”。律只有看见或收到它，才知道这份材料在谁手里；不能读背包。礼物归属改变不自动把未展示的全文广播给所有人。

固定副本各有独立实体和来源。需要复制时必须是后续明确批准的行动；本版没有无限复制按钮。`E12/E13` 是本章书写行为产生的新文书，不是按需刷出的旧证据。

## 6. 拜访与线索路线

没有固定“先小春、再医生、再警员”的解锁顺序。以下是可测试路线，不是强制路线。

### 路线 A：从遗书入手

小春提出疑问 → 商店街读旧报 → 经律或小春得知旅馆 → 千代展示原信 → 对照公开摘录 → 向律追问编辑行为或找犬饲查摘要。

### 路线 B：先怀疑九条，再核对时间

商店街与九条交谈 → 九条指向纱夜 → 车站查看值班页 → 发现作恶者未必是现场凶手 → 继续查委托或向犬饲核对抄件。

### 路线 C：先整理遗物

小春或千代提到雨宫家旧居 → 遥前去整理 → 读取录音卡 → 向律追问假报道 → 律得知玩家握有这段录音；若玩家不告诉他，他不能自动得知。

### 路线 D：先听医学记录

警署或纱夜提到诊所 → 桐生解释检查记录 → 发现“医学证明自杀”的转述不准确 → 带着差异追问犬饲，而不是让医生直接解答凶手。

### 路线 E：只想帮千代

在旅馆日常来往 → 千代决定纠正证词 → 玩家选择陪同、转告或离开 → 可能进入保护／撞见分支，即使还没有收齐原案全部材料也成立。

## 7. 证据损失与多来源

- 原信失去后，`E04` 仍可能证明全文存在；它是独立的既存材料，但真实性和来源仍可被质疑。
- 纱夜无法继续交流时，`E06` 可保留时间记录；失去她的解释仍然有代价。
- 桐生不在时可向犬饲问 `E11`；医生本人缺席不会把卷宗也删除。
- 千代未留下 `E12` 就死亡，玩家可能失去直接纠正其旧证词的机会。委托、录音、医学和时间线仍可查，不能事后凭空获得她没写过的声明。
- `E07/E09` 分别从委托与录音支持假报道交易；两者仍不等于完整的杀人证明。
- 玩家只凭猜测点中律，不自动揭开全部真相。对质承认、行为暴露、证词组合和公开指控是不同结果；游戏结局不伪造正式司法定罪。
- 有些路会失去。目标是避免单一物品一丢就无法继续游玩，而不是保证玩家一定获得最完整结局。

## 8. 后续实现的验收点

- 地图始终最多八点；任何已展示的明确地点都不会还显示“未发现”。
- 到达地点不自动聊天；没有 NPC 时仍能进入场景，公开材料和现有事件不因 NPC 缺席消失。
- 九条与律同在商店街时可分别选择，不能随机把其中一人藏掉。
- 展示不自动转移物品；交付不重复发奖；赠送重要物品不被硬性拒绝。
- 未亲耳听到、未收到消息的 NPC 不获知玩家进展。
- 副本有固定开局来源；新说明有实际书写事件；死亡不自动生遗书。
- 角色卡引用的 `F/E/loc` 编号必须能在本文找到，未知编号不送入 AI。
- 材料之间的矛盾是固定设计，不允许模型为“更戏剧性”更改全文、时间、凶手或录音内容。

本轮只确定内容与状态边界。调查动作的具体耗时、UI摆放和接口结构在代码重构阶段结合现有资源机制实现，不在此处另加数值体系。
