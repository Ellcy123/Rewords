## 群像连续性

- 四人和小鑫同处一个写实末日世界，但不穿完全相同的制服。
- 合成时以各自人物卡右侧脸部特写锁定身份，以三视图锁定服装结构和身材比例。
- 不互换发型、服装主色、胸前设备或腰部道具。
- 伤痕仅为轻微擦伤、烟灰和雨水，不新增血腥重伤。
- 当前人物卡代表获救后的稳定身份造型；若制作求救阶段画面，只增加环境污损与疲惫，不更换脸和基础服装。
