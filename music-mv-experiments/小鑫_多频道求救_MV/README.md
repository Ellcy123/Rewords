# 小鑫《多频道求救》MV

## 当前目标

用 MiniMax H3 制作一支 63.121 秒、16:9、电影感末日叙事 MV。核心不是“打丧尸”，而是表现小鑫在同时答应所有人之后，被选择本身困住：嘴上一直说马上到，身体最终停在岔路口。

当前视觉方案采用“剧情线＋唱跳线”交叉剪辑：17.758 秒可见唱跳，四位获救者作为四个频道的人格化伴舞。MiniMax 提示词正式执行以 V0.5 汇总和 `runninghub_h3_v0.6/` 为准；更早版本只作历史记录。

MiniMax 中凡出现小鑫，统一附加 `references/小鑫_MiniMax专用角色卡_站立面部模糊_V0.2.png`；右侧清晰特写锁定面部，左侧模糊脸的站立图只锁定服装和体型。

RunningHub 的参考音频只用于口型、节奏和音色控制，不保证生成音轨与原歌一致。所有视频下载后删除模型音轨并重新铺设原始歌曲；S01、S02、S03 的偏念白额外使用 `references/audio/小鑫_音色参考_12.715s.wav`。

## 已确认输入

- 音频：`sources/小鑫_多频道求救_音频.mp3`
- 时长：63.121 秒
- 主节拍：约 136 BPM
- 人物参考：`references/` 下 3 张小鑫参考图
- 感染者参考：`references/infected/尸潮远景群体参考_V0.4.png`，只控制远景群体轮廓、步态、间距和雾中密度，不作为固定丧尸角色卡
- 四位获救者：`references/survivors/` 下 4 张末日人物卡及对应原始身份参考
- 歌词：`sources/歌词.txt`
- 目标模型：MiniMax H3，单次生成控制在 4–15 秒以内
- 成片默认：16:9、24 fps、1920×1080；关键构图保留中心安全区，方便后续裁切 9:16
