## 动态规则

- 动态来自清晰的重心移动、步法、手臂路径、群体连锁和硬切，不靠抖动、速度拉升、甩镜或无意义乱跳。
- 所有动作在首 0.25 秒开始；每一镜都至少完成一个可读的 4–8 拍短组合，不能长时间定格等待。
- 仍保留五人、非等距、无接触、无平排 W/V、无跳跃/旋转、肢体分离这些稳定性底线。
- S10 的原歌继续在后期精确铺设。因为没有可辨认口型，H3 参考音频的非精确同步不会再破坏画面。
