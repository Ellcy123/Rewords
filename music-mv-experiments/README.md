## MV 使用判断

这套工作流适合生成 MV 的单镜头或短分段，并利用参考音频控制节奏、情绪、声音质感或口型。参考音频不保证原样保留；需要精确保留歌曲时，应在后期以原始音乐重新混音或封装。
